## 从 N0 的剩余错误中学到什么

原始表的归档 SHA-256 为 `8d2b86babfd312392c7ded6029cfe4dba84486d172ee299d0402f315429cfa77`。脚本还原归档 BOM 和 CRLF 后验摘要。使用 1,740 条历史记录中的 N0 两种子 348 条，按图像与路径 ID 配对；原始路径全集为 174，Dev28 有 18 图含目标。

- 共 33 条在两个种子中都部分命中。14 条（6 图）在两个种子中均只有一个邻域区间，且所有命中位置相邻；遗漏只可能在区间一端或两端。4 条（3 图）两次都可证明有内部遗漏。15 条在当前表中不能归为这两种双种子一致类型。12 条在两个种子中邻域部分均零命中，106 条均完全命中。
- 对原生八邻接图，每条边为 1 或 √2 像素。由总边长与双端命中边长分别解出整数边数；必须有唯一解。对坐标无重复的有效区间，命中串数 = 命中点数 − 双端命中边数。命中串数超过邻域区间数时，至少存在一个内部缺口；单区间只有一个命中串时，仅可能在区间端部遗漏。用 9,832 个小规模掩膜与命中模式穷举核对。端部指与邻域相交后的区间端部，医学血管终点未经确认。
- 图 31934 路径 231 两种子命中 37/48、42/48，两次均只漏区间端部。图 35276 路径 250 命中 31/60、30/60，两次均有内部缺口。图 51655 路径 311 两次均 0/27。位置计数上下界显示，33 条中两种子共同漏掉的路径位置出现次数合计至少 180、至多 444；不同路径可能共享锚点。两次漏在同一端、缺口长度和生理解剖连续性均不能由该表确定。
- 同图同路径比较现有 NL，在 14 条端部遗漏路径中，两种子的总命中变化分别为 −15、−57 个位置出现次数。该子集按 N0 结果选出，仅用于说明旧改动表现；不能用于新方法主评价或估计独立效果。

## 训练准备与第一个 GPU 动作

已核对 Train110 与 Dev28 标识无交集。历史 Train 图像中 73 张有非空邻域，68 张有邻域血管标签，共 188,004 个邻域血管像素；其中细路径覆盖量仍需真实文件计算。Train 全视野原候选为 13,325 条。Train 掩膜只取冻结候选与有效出血邻域的交集，训练抽样不读 Dev 误差、病例名单或预测。

保留一个可撤回的工程候选：标准 nnU-Net 的主分割损失不动，在最高分辨率的血管/背景 logit 上加辅助项。每条路径等权，先算邻域内本路径的平均正类 BCE，再按图内路径平均；同图同邻域合法背景的负类 BCE 与正项等权。无目标的裁块辅助项为零，只有目标没有背景时保留正项。共享坐标允许出现在不同路径中，路径内去重。该原型直接监督中心位置，能否带来 d1 覆盖收益要实测。它既不补造像素，也不要求预测在两个端点之间连线。初步选择这种监督是为了覆盖不同宽度和长度的候选，而 14/4 的计数支持暂缓专门的中段桥接假说。辅助项系数及科学训练预算均未根据 Dev 表选择。

以下是原始文件依赖及原定检查的记录。第 1 项可以从 PR 归档执行，第 2–5 项因原件丢失而关闭：

1. `python audit_paths.py` 复算逐路径表。
2. `python replay_n0.py <A7项目根> n0_common_spans.json` 校验 28 份有序参考和 56 份 N0 概率 SHA。交叉形 d1 与固定阈值 0.5，逐条核对两种子的命中与参考分母；输出共同漏段坐标、弧长、两侧是否都命中。跨不确定区或离开邻域即截断。
3. `python inventory_train.py <A7项目根> train_near_paths.csv` 校验候选分支表、Train110 原路径、B2 掩膜、出血和所需的不确定区标注，计算每图可用目标。无出血的图无邻域目标。比较新增参考覆盖、按图集中度和零目标图。输出文件用新名字。
4. 在 A7 的 nnU-Net 原生训练加载器中，将同一次采样、裁剪、镜像和仿射变换同步作用到各路径与有效邻域，和变换后原始 GT 核对。保留空目标批次、正负像素数、路径数和无效坐标；核对开启辅助项前后输入、基础标签及随机状态一致。此集成尚待真实环境实施。若有重复映射或出界，先按原图确定正确几何，不能靠填补路径处理。
5. **第一项 GPU 工作是一个真实 Train 配对批次的工程检查**：同一初始权重、输入、增强和随机状态，分别计算 N0 基础损失和基础加辅助的前反向，检查梯度有限、辅助项对目标有作用、显存能容纳。工程检查不作优化器更新。该批可核验工程可用性，不能评价召回收益。

后续如比较模型，使用固定 0.5、全部 18 图/174 路径，报告图内路径平均后跨图等权的邻域 d1，以及同一邻域 FP/面积、逐图得失、独立的原 9 图/77 点读数。整段零命中、d0、边覆盖与局部漏段作解释项。全图 Dice、Precision、FP/FOV 和远处召回作保护项，同时给出两个种子各自的结果与以图为单位的配对区间。可接受代价尚待确定；没有以旧结果倒推阈值。Test 未使用。
