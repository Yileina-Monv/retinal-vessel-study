# MAPLES 本机开发验证：2026-10-11

2026-10-19 同步已有 JSON/CSV，没有新增训练、推理或阈值校准。导入清单与源文件 SHA-256 见 source_manifest.json。

## 模型与材料

- M0/Z0：FIVES 预训练 M0 直接评价 MAPLES，Z0 是评价名称。
- M1：FIVES 上独立训练的骨架召回强化对照，不是 TW。
- step200：从 M0 出发，仅三张 MAPLES train 图普通微调至 200 步的工程检查点，不是正式 T0。
- 三者使用同 28 张 Dev。step200 见过 MAPLES train，M0/M1 没有，不是仅改变损失的公平消融。

z0/、m1/、step200/ 各含 summary.json、per_image_metrics.csv、exploratory_regions.csv；后两者另有 comparison.json。matched_fp/ 含 comparison.json 和 per_image.csv。

文件为选定统计的原字节副本，保留公开数据集图像编号；不包含原图、标签、模型、概率、个人信息或机器路径。实际推理使用本机历史代码副本，本次没有迁入完整运行代码与依赖，不能声称克隆即可复现。历史复核记录存在于本机，本次仅同步统计与导入校验。

## 固定阈值 0.5

全 FOV 图像宏平均，n=28，单位为 %。

| 模型 | Dice | Precision | Recall | FP/FOV |
| --- | ---: | ---: | ---: | ---: |
| M0/Z0 | 75.892 | 89.301 | 66.328 | 1.163 |
| M1 | 76.005 | 89.722 | 66.293 | 1.112 |
| step200 | 80.279 | 79.571 | 81.600 | 3.146 |

200 步提高召回，同时明显增加误报。FP/FOV 的分母是 FOV 像素，不是常规背景分母的 FPR。

目标为 M0@0.5 的宏平均 FP/FOV=1.16341063995%。每模型一个全局阈值，匹配整体宏平均，不保证每图或每邻域误报相等。M0 是固定锚点；M1/step200 选不超过目标的最低可行 float32 阈值。

## 区域与统计口径

- 出血膨胀半径=max(1, floor(0.01×W_ROI+0.5))，W_ROI 为半开 ROI 宽度；先膨胀完整病灶再排除 U，骨架由完整 V∩F 生成后取区域子集。
- 细血管按局部半径分档，匹配容差为 1px；零分母保留 NA，不能当 0。
- 固定阈值 comparison.json 的 1000 次图像 Bootstrap 区间为描述性，患者对应未知，未作多重比较校正。
- 本地划分为 110 train / 28 Dev / 60 官方 Test；本轮效果评价没有使用 Test，历史数据审计涉及过测试侧材料。
- 这里的半径分档、区域半径和有效样本，与正式主指标不同，不直接比较细骨架召回数值。

正式实验与材料缺口见 [10 月 19 日阶段进展](../../docs/research/stage2_progress_20261019.md)。
