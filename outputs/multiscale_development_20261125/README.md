# 双尺度推理的跨种子、跨数据集开发集验证

比较 0.75×、1×、1.25×、1.5×、2× 及其十种两两等权组合。研究目标是提高出血邻域细血管骨架召回，同时将远处召回和 Dice 相对原生 1× 的下降各控制在 1 个百分点以内。

## 实验与决定

U-Net 从同一 FIVES 权重初始化，用相同的 MAPLES Train110 流程微调 2,000 步，只替换随机种子。每图按视野和分辨率换算角宽。细骨架宽度上限为 0.15°，出血外缘邻域为 0.45°，D1 的命中容差为 0.05°。每个权重在 MAPLES Dev28 按局部误报 15/千的预算校准阈值，再冻结到 IDRiD Dev54。分别有 15 和 51 张图具备局部召回的有效分母。IDRiD 官方测试 27 张继续封存。

[两种子全部 15 组的开发集均值](scale_grid.csv) 包含两地的图均 D1、远处召回、Dice 和局部误报。每个种子在源域先检查保护条件，再在可行双尺度中选 D1 最高者。下表为选出的 1×+1.5× 相对单 1× 的百分点变化。

| 模型与数据集 | 病灶邻域 D1 | 远处召回 | Dice |
|---|---:|---:|---:|
| 种子 2027，MAPLES | +19.74 | −0.02 | +0.53 |
| 种子 2028，MAPLES | +19.15 | +0.45 | +0.42 |
| 种子 2027，IDRiD | +6.69 | +0.55 | +1.13 |
| 种子 2028，IDRiD | +4.42 | +0.73 | +0.80 |

两个种子都选中 1×+1.5×。种子 2028 在 IDRiD 上，单 1.25× 的 D1 为 50.76%，双尺度为 50.79%；优势取决于参照尺度和保护指标。源域病例重抽样 1,500 次，要求两个种子均通过保护且最大化较差种子增益时，1×+1.5× 在 86.0% 的重抽样中满足保护，在 48.3% 中排第一。将它冻结为当前主候选，保留单 1.25× 和 0.75×+1.5× 为强对照。

## 机制与迁移边界

等窗口数对照中，原种子真实双尺度相对原生尺度加密滑窗的融合，在 MAPLES 和 IDRiD 上分别高 18.49、5.18 个百分点。等视野特征替换时，换入放大分支的深层解码特征保留了大部分源域校准后的收益。输入局部对比度增强 35% 的单 1× 仍低于原图双尺度。上述观察支持像素尺度影响模型表征，具体效应受阈值及训练配置影响。

以单 1.25× 为默认，仅在局部暗区使用 1×+1.5×，需要三次尺度前向。在 IDRiD 开发集上，该方法相对单 1.25× 的图均 D1 在两个种子分别提高 2.26 和 0.68 个百分点。先在同一图内平均两个种子，再按图配对重抽样，图均增益为 +1.47 [0.26, 3.02]，按点增益为 +0.67 [−0.07, 1.53]。新种子暗区规则重新源域标定后，在 MAPLES 和 IDRiD 的实际误报分别为 14.86 和 23.62/千，目标域误报仍需单独报告。

标准 nnU-Net 的旧版折外存档中，1×+2× 相对原生局部 D1 +5.04、远处召回 −8.49、Dice −5.29 个百分点。统一角宽的新八阶段实验是简化拓扑对照。完整标准 nnU-Net 的 1×+1.5× 仍待同口径实测。[历史归档](https://github.com/Yileina-Monv/retinal-vessel-study/pull/22)
