# 现有双尺度证据的敏感性复核

复核对象为 seed 2027 的 Refined IDRiD 首折 U-Net 与标准 nnU-Net，18 张留出图及冻结至 MAPLES Dev28 的反向迁移。分析使用原已保存的逐图结果与 IDRiD 原图、角网格概率。所有新增检验均为探索性。单位为百分点。

| 检验 | U-Net | nnU-Net |
|---|---:|---:|
| IDRiD 融合减 1× 的图均 D1 | +11.21 | +1.82 |
| IDRiD 图均 D0 | +7.51 | −5.57 |
| 标定图与评估图均重抽后的 D1 差 95% 区间 | [2.08,22.84] | [−2.35,9.15] |
| IDRiD 视场用 47.5° / 50° / 52.5° 时的图均 D1 差 | +10.54 / +11.21 / +10.29 | +0.75 / +1.82 / +1.50 |
| MAPLES 所有有效图 / 至少五个目标点图的图均 D1 差 | +14.16 / +6.54 | +4.85 / +5.63 |
| MAPLES 所有目标点合并计算的 D1 差 | +10.47 | +7.56 |
| MAPLES 两支均定阈值 0.5 时的图均 D1 差 | +3.22 | +13.70 |

IDRiD 首折模型间 D1 增益差 +9.38，条件于固定阈值的图像配对区间 [1.74,20.30]。MAPLES 的相应差 +9.31 [−2.05,24.95]，共用 0.5 则为 −10.48 [−25.23,−1.07]。阈值标定图与训练图重合。源域重抽样固定权重，只改变参与阈值选择的图像构成，不模拟重新训练。视角扰动保留原阈值并重建目标与评分区域；候选点从 1108 变到 804，50° 的结果逐图重放一致。

远区对照在 IDRiD 18 张图上逐图精确匹配融合与 1× 的远区假阳性像素总数。U-Net 远区召回差 +1.90 [1.17,2.63]，nnU-Net −1.34 [−2.28,−0.43]。nnU-Net 全远区像素 ROC AUC 差按百分数为 −0.035 [−0.210,0.130]。冻结阈值下远区总损失 −2.50，其中离真值背景超过 √2 个参考像素的内侧贡献 −1.94，边缘贡献 −0.56，分母均为全远区血管像素。对概率图和阈值的两个更换顺序取均值，nnU-Net 两项贡献分别为 −5.72、+3.21。匹配远区误报使用了留出真值，只用于诊断。

运行次序为 check.py、source_bootstrap.py、angle_check.py，使用首折实验的 Python 环境。每项百分位区间基于图像配对自助重抽样 20,000 次；不校正整项研究的候选筛选，也不包括患者聚类及重训不确定性。同目录 CSV 保存汇总量与区间，逐图明细由复算脚本在本地生成。
