# 从两轮 TW 分析出发：目前知道什么，下一步怎样验证

2026-10-19。这里是 MAPLES-DR 出血邻域细血管召回研究的阅读入口，整合两轮 Pro 报告及各自实验卡。先给出当前结果，再解释它能回答什么、还不能回答什么，以及下一步实验应在什么条件下进入。

**目前的判断是：TW 没有证明比普通微调 T0 带来稳定且受保护的细血管召回收益。** 这不是对所有区域加权方法的否定，也没有找到一个已被证实的失败原因。最有价值的下一步，是看清已有预测在相同位置上究竟发生了什么，再决定是否值得新增训练。

本目录记录的是研究解释和**未采纳的实验建议**。本次没有启动训练、模型推理、概率重算、梯度探针或官方 Test 评价；文中的新预算、+3 个百分点门槛和新增保护条件，都没有因此变成冻结协议。

## 研究问题与 T0/TW 的区别

项目关注的不是只让全图 Dice 更高，而是：在出血附近，能否多找回真正的细血管，同时不增加误报、错误连接，也不牺牲远离病灶的召回？全图指标可能掩盖局部得失，因此“Recall 更高”或“Dice 更高”不能单独回答这个问题。

正式 T0/TW 都从同一个 FIVES M0 出发，用 MAPLES Train110 微调，在 Dev28 上比较；种子为 2026/2027/2028，每条轨迹 2000 次成功更新，固定终点与 0.5 阈值。T0 使用 FOV 内 BCE 加未加权 Dice。TW 将确定出血内部及其外侧邻域 A 内的血管和背景 BCE 权重都提高到 2，A 外为 1，Dice 不加权。

这里有一个关键区别：**加权区域 A 不等于主评价的细血管目标 T。** A 包括出血内部、粗血管、容易检测的血管和背景；主目标只取出血外邻域 Rnear 内、原尺寸宽度代理 `2×EDT≤3` 的参考骨架位置，允许欧氏距离不超过 1 像素的匹配。U 是病灶不确定标签的并集，只从额外加权和区域评价中排除，仍参与基线 FOV BCE、Dice 和全图指标，不能当作基础训练 ignore。

主指标只有 9 张有效图、77 个参考位置；另 19 图零分母为 NA，不能填 0。先同图同 seed 配对，跨 seed 平均，再对 9 图宏平均。near 像素召回有 18 张有效图，全图与 far 指标有 28 张。77 点和 231 个位置×seed 计数都不是独立样本；患者对应关系仍未知。

历史 Z0 是零样本，FIVES M1 是 soft-recall 机制对照，本机 step200 只是 3 张 MAPLES Train 图、200 更新的工程检查点。M1 不是 TW，step200 不是正式 T0。本机 10 月 11 日 `radius≤2` 的 15 图、302 位置，也不能与正式 9 图、77 位置拼成一条结果曲线。

## 最新主结果和保护指标

以下差值都是 **TW−T0，单位为百分点 pp**，CI 是锁定 PR #7 的图像 bootstrap 95% 区间。CSV 原值为比例，转换为 pp 时乘 100。当前数值取自[配对汇总 CSV](https://github.com/Yileina-Monv/retinal-vessel-study/blob/28a281fa2be1167533bcd0a54eca544a6e1f565d/outputs/maples_training_results_20261019/paired_comparison_summary.csv)，不是用正文舍入值倒推。

| 指标 | T0 / TW 水平 | 差值 pp | 95% CI，pp | 说明 |
|---|---|---:|---|---|
| 邻域细骨架主召回，9 图 | 51.0580% / 50.4579% | −0.600137 | [−1.526063,0] | 三 seed 差分别 −1.388889、0、−0.411523 pp，没有正 seed |
| near 像素召回，18 图 | 61.3529% / 61.0871% | −0.265818 | [−0.516224,−0.109814] | 负方向不限于稀疏骨架位置 |
| Precision，28 图 | 85.7337% / 85.7941% | +0.060485 | [+0.015556,+0.115092] | 小幅提高不能补偿其他保护失败 |
| FP/FOV，28 图 | 2.0251% / 2.0130% | −0.012149 | [−0.023516,−0.003577] | 全图误报下降不等于 near 误报下降 |
| far Recall，28 图 | 82.0782% / 82.0377% | −0.040537 | [−0.071019,−0.017736] | 原零恶化保护未通过 |

主区间包含 0，因此不应写“主指标显著更差”；准确表述是没有达到原先要求的稳定、受保护收益。far 下降幅度很小，也不能事后放宽已冻结的保护，更不能把它扩大解释成临床损害。

主指标总命中 T0 为 106/231，TW 为 104/231，净少 2。净下降来自两个图×seed 单元：一处 8/8→7/8，另一处 10/27→9/27。仅凭这些边际计数，不能排除其他单元内的找回与丢失对消。类别 2/1 的总命中仍是 106/231，宏均值虽比 T0 高 0.315237 pp，却伴随 Precision 降、FP 增，不能称为普遍或无代价找回。

加大均匀权重没有形成稳定收益。seed2026 延长到 4000 后，T0 和 TW 自身召回均提高，但 Precision 降、FP 增；同预算 4000 的 TW−T0 主差仍为 −3.6008 pp，CI [−9.1564,0] 是**触零**。预算交互差 −2.2119 pp、CI [−8.5905,+3.3436] 才是**跨零**。既不能宣布差距显著扩大，也不能证明已收敛。

17 个配置是 15 条从 M0 开始的轨迹加 2 段续训，共记录 34,000 成功更新。190 个 loss 窗口含 20 个重复前缀，唯一窗口 170；它不是 38,000 个独立更新。loss 仍下降不能单独证明严重欠拟合，也不构成继续加预算的理由。

阶段 PDF 的同 FP 结果仍属于报告级：共同 Z0@0.5 宏 FP/FOV 预算约 1.16341%，2000 时 T0/TW 主召回为 44.154%/43.996%，4000 都为 40.292%。PR #7 尚未给出对应阈值及曲线，本次没有独立重算；一个全局误报工作点也不能保证局部误报或结构正确。

## 已知事实与还在竞争的解释

Plan B 来源摘要报告 11 条件、308 张既有预测；77 位置中 27 始终漏、33 始终中、17 变化，T0/TW 三 seed 全漏 39/40，231 成对点位×seed 恢复 0、损失 2。**定量已完成与逐点独立验证是两件事。** 公开包没有 point_id、坐标、77×11 联合矩阵或概率，本次只能验证固定分母和净差 −2，不能从逐图总数唯一恢复这些联合集合。

稳定未命中不等于不可见、整支消失或不可分，q=0.499 也会始终漏。549,260 个重复预测上的参考相对 FP 组件不是独立错误或临床假血管数。人工仍 0/105，AI 辅助视觉结果未公开，不能代填人工复核。

| 解释方向 | 为什么值得查 | 还缺什么，什么结果会改变判断 |
|---|---|---|
| 分类取舍改变 | TW 的 Precision↑、FP↓、near/far↓，类别 2/1 反向变化 | 缺同点概率、near FP与局部排序；若有稳定真实结构找回和排序改善，仅被阈值遮住，就削弱“主要只是取舍” |
| 真目标曝光不足 | A≠T，区域像素少不等于目标被充分见过 | 需要 Train 每图/链/点真实曝光；如果已充分覆盖且单槽不能改变曝光，就不应默认做采样 |
| 几何或结构错误 | d1 对细目标和1像素偏移敏感 | 缺实际对齐、法向剖面、完整链及新连接；不能提前断言偏移、断裂或增粗占主导 |
| 可见性、参考与随机性 | 9图77点、患者未知、Dev反复使用、人工未完成 | 需匿名人工判断和逐图影响性；不以“难/标注疑点”为理由删除不利 Dev |

背景多不能推出背景梯度主导，BCE/Dice 数值不能替代共享参数梯度，目标不同也不能直接推出“Dice 压制细血管”。这些都仍是假说。

## 先做哪些零训练诊断

优先复用既有 Plan B，不重复索取已公开均值，也不为了检查重新推理。建议顺序如下；Train 曝光重放可与概率材料工作并行。

1. **D0：先重现几何和正式评价。** 对齐实际源码/配置、完整图上膨胀/骨架/EDT、crop/增强、原尺寸还原与阈值顺序，重现 9 图 77 个坐标 hash 和计数。欧氏 d1 不是整个 3×3。不能复现就先修证据链，不暗改容差。
2. **D1：恢复联合位置状态。** 用同 point_id 比较 T0/TW 与 11 条件，检查找回/丢失、27/33/17 和 0/2，再按完整参考链和图归并。
3. **D2：区分低分与反向排序。** 同时看中心概率和与正式支撑一致的 q；背景也取同形状邻域最大值。画统一全局阈值下主/near/far、全图/near FP和结构曲线。单调校准不能修复正负排序颠倒。
4. **D3：查看真实结构。** d0–d3只作诊断，结合位移、法向宽度、完整链缺口及所有找回/丢失的局部FP和新连接。只增粗或背景团块命中不算真实细血管收益。
5. **D4：完成匿名人工复核。** 建议77点全看，先RGB再参考和匿名预测，两人独立并保留分歧；AI不算人工。参考修订保留旧主结果，另作敏感性分析。
6. **D5：只用Train重放曝光。** 重放8000真实draw，列每图/链/点曝光、零曝光、低四分位和边界截断，再模拟S1/Cnear。不能用Dev漏点生成Train名单。

这里“零训练”并不表示这些材料已取得或这些图像诊断已完成。本 PR 完成的是公开数表检查：87个汇总均值、40个多seed SD通过；63/87比较完整贯通 endpoint→paired→summary，另24缺部分基线endpoint，只能检查paired→summary。真实概率与运行层仍待补齐。

## 最多三项实验：按诊断进入，不叠加开跑

### S1：只改变一个裁块槽，检验目标曝光

只有在几何、联合位置和盲审可靠，且 Train 目标曝光不足、能被单槽改变时，才考虑 S1。有T图每轮4槽只轮转替换1槽top-left，完整链→T点→固定jitter；其他槽、所有增强、图频次、损失和网络不变。对照为同期C0、S1、Cnear。原则保留Cnear；仅实际窗口/变换完全相同时合并，省略时只能归因为裁块分布变化。

训练前建议纯重放8000 draw：按图每点曝光中位数至少为C0的1.25倍，固定C0最低四分位图逐图不降，至少半数目标图增加；若C0中位数为0，S1中位数至少1次/点。操纵弱、集中少数链或严重丢失上下文就停止。

机制预算提案是2 seed×440成功更新/臂，只比较固定Train probes与同期C0@440，两个seed分别判断；至少半数目标Train图平均q差正，图中位目标−背景间隔差正。440步不能判正式收益。若进入效果阶段，各臂重新从共同M0起步，3 seed×2000固定终点。Train响应明确而Dev无保护收益，不自动加采样比例。

### E2：对低概率真实目标加正例纠错

仅当对齐、可见、曝光充分，目标局部排序合理却低于阈值，而且一个统一阈值不能同时保护误报与far时考虑。只在T0上添加真实T的正例BCE，采样不变；对照T0、目标正例BCE、同T的soft-recall。空目标裁块为0，不能把1像素容差膨胀区全标正。

剂量建议用32个固定Train小批、最后解码块的初始梯度范数，按0.1倍基线/辅助RMS比例确定后固定，不用Dev调λ。机制/效果预算同S1，须有相对同期C0的目标q和局部间隔响应。只统一抬分、只Train改善、FP换Recall或增粗均不采纳；若目标实际上低于局部背景，应撤销E2优先级而转查E3。

### E3：对目标与附近困难背景做局部排序

仅当可见、对齐、曝光充分且局部排序反向时考虑，还须在E3自己的12像素局部域与中心logit上确认，不能直接用D2的32像素/d1最大概率代替。保持T0采样和基础loss，只增加目标−背景logit排序项；背景须在A∩Ω内、距参考V为2–8像素、距目标≤12，完整图预计算后与当前crop相交并同步变换。

对照T0、半困难/半均匀排序、同范围同对数的全均匀排序；两排序臂共用锚点、每点对数及由全均匀臂确定的λ。无合法背景就跳过，不能改抽远处容易背景。机制/效果预算同前；既要局部间隔增加，也要目标q相对同期C0响应。只压低背景、只排序改善或出现错误连接/far损失不算成功。E2/E3由诊断选择，不与S1自动叠加。

## 哪些是原要求，哪些仍待讨论

原正式比较固定0.5、原尺寸2×EDT≤3、欧氏d1、9图宏平均，要求三seed主差正且按图CI下界>0，并按原冻结规则守住Precision、FP/FOV与far召回的零恶化保护。原文未完整说明所有等号和逐seed保护细则，仍须正式protocol。TW目前未过不需要借助任何新门槛。

下列是两轮分析提出的**新建议，尚未采纳**：主差≥+3pp；≥3/9图净改善、所有LOO正、总净hit正；新增near FP、无参考骨架密度CI与错误连接审核；2seed×440机制阶段；重新M0起步3seed×2000效果阶段；10000次bootstrap；同FP必要辅助检查。+3pp是工程资源门槛，不是临床差异或功效保证。

建议的正式采纳要同时满足固定0.5主收益、全部保护与同FP辅助。保护提议为Precision/far差CI下界≥0，全图FP/FOV、near FP/固定面积、无参考骨架密度差CI上界≤0，无确认新增错误连接，疑点不自动通过。同FP共用正式Z0预算，所有方法/seed均取.001网格最低可行全局阈值，每seed主差正、near FP不增、far不降并有结构支持，不另要求+3pp；它在同Dev选阈值，仍是描述性。

2000是同预算比较，不是收敛声明。4000必须在查看新Dev指标/概率/结构之前共同另行注册，不能在2000失败后只给候选第二次采纳机会。区间不确定不能当无伤害，也不能自动证明机制无效。官方Test须留到方法、阈值、预算、实现与保护另行采纳并冻结之后。
