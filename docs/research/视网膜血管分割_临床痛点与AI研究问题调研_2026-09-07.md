## 1. Executive Summary

### 1.1 一句话推荐

**在跨疾病彩色眼底定量研究中，常规血管分割是否因可见细血管漏检和伪血管产生而扭曲骨架长度密度代理，以及能否通过测量导向的工作点选择或针对性训练，在控制误检的前提下减少这种偏差？**

这里的“骨架长度密度代理”是公开图像上的数字测量，不是真实微米尺度的毛细血管密度，不代表血流灌注。建议首先使用可重复的骨架像素密度，几何加权长度作为次要测量，避免一开始就把复杂图重建误差混入主要终点。

### 1.2 为什么选择它

临床研究真正需要的是：从眼底照片提取的血管表型能够稳定、可比地反映图像中可见的血管结构，而不是随模型、阈值或图像质量变化而明显改变。已有研究确实使用密度、管径、迂曲度等表型研究眼病及全身血管风险；但“有疾病关联”“测量可靠”“加入预测模型有额外价值”是三个不同命题。[L02–L10]

**本项目能直接验证第二个命题的一部分：相对于现有人工标签的测量一致性。** 它不能用 FIVES 证明改善心血管事件预测、青光眼诊断或治疗决策。

已有研究也给出必要反证：AutoMorph 已开展形态指标一致性评价，部分指标在像素分割并不完美时仍具有较好一致性；重测研究显示不同指标的可靠性并不相同。因此，“Dice 不够”不是本项目已经成立的结论，更不是新颖性本身。[L02–L04]

**M1/C1 不再作为默认研究主线。** M1 的现有结果值得保留，但其细血管召回收益是否转化为测量收益尚未验证；C1 有可运行组件与工程检查，但没有完成研究效果对照。是否继续某种损失，应由新问题的误差分解决定，而不是由已有代码决定。[R01–R04]

### 2.5 数据与评价资产的真实边界

FIVES 当前副本来自固定版本镜像，两个镜像的 PNG 和质量记录交叉一致，但未完成与官方 Figshare 原包的密码学校验。800 图中有 794 种不同的原图像素内容；六组同图不同标签，其中一组位于官方 test。未发现像素完全相同的图像跨越官方 train/test，但这不证明患者独立。[R05]

原始字段是 `Disease/Number/IC/Blur/LC`，三项质量编码均为 1=好、0=差。不能把二值原始字段擅自解释成连续可见性、局部标签置信度或疾病严重程度。118 图的疾病×质量交叉分布仍须从当前 manifest 正式重建，不拿整个 600 图的比例代替。[R05]

当前评价函数返回 `fov_pixels`、`label_pixels`、`predicted_pixels`，因此已有原始逐图结果若保留这些字段，可零推理计算面积误差。此次读取的 `paired_final_metrics.csv` 是长格式指标表，局部复核 `images.csv` 也不直接包含完整面积字段；**代码支持某字段，不等于当前归档 CSV 一定保存了它**。[R11、R14]

## 3. 眼底血管分割到底被拿来做什么

### 3.1 它通常是 B，也可能服务于 C，而不是 A

对“血管定量表型”工作流，通常是：

**眼底采集 → 图像质量与有效区域检查 → 血管/动静脉/视盘等结构提取 → 表型测量 → 统计关联、随访比较或风险模型 → 医学解释。**

这对应 **B：中间测量步骤**。当这些表型进入疾病分类、风险预测或辅助决策系统时，又成为 **C：其他系统的输入**。二值血管图本身通常不是最终的 DR、青光眼或 AMD 诊断；具有好看的血管掩膜不等于完成临床诊断。[L02、L08]

一个关键反例来自心血管研究：AI 血管测量可用于构建并外部验证风险模型，但在 Rudnicka 等的研究中，把血管特征加入既有 Framingham 风险模型，并未改善心肌梗死和卒中的整体预测表现。**测得到、有关联、能提升既有决策，不是同一件事。**[L08]

### 3.2 定量表型的用途和前提

| 表型 | 实际反映什么 | 有意义的研究用途 | 当前 FIVES 能做到什么 |
|---|---|---|---|
| Vessel area / area density | 被标为血管的面积及其占 ROI 比例，混合了长度和宽度 | 血管网络占据程度、眼病及系统性血管表型研究 | 可直接计算标签相对误差；不代表灌注量 |
| Skeleton vessel density / length density | 去除主要宽度影响后的网络延伸程度；定义依赖骨架算法 | 网络稀疏化、青光眼相关微血管研究 | 可计算离散骨架密度与数字长度代理；不是毛细血管检测 |
| Caliber / diameter / width distribution | 血管宽度及宽度组成 | 血压、动脉硬化和血管风险相关表型 | 只能得到数字宽度代理；混合动静脉、标定缺失 |
| CRAE / CRVE | 按特定采样区和合并公式得到的中央动/静脉口径等效值 | 标准化的动静脉口径研究 | 仅二值标签不够；还需动静脉身份、视盘定位、管段选择规范 |
| AVR | CRAE 与 CRVE 的比值 | 动静脉相对口径表型 | 比值可能抵消共同尺度误差，但不能抵消类别错分与管段漏选 |
| Tortuosity | 血管路径相对端点距离的弯曲程度，或曲率类量 | DR 风险/进展、血管风险、部分眼病表型 | 可研究标签路径上的代理；完整管段匹配是前提 |
| Branching angle | 母支与分支的方向关系 | DR 等疾病中的网络几何改变 | 分叉身份和交叉歧义使其不宜成为当前主要终点 |
| Bifurcation count / branching complexity | 网络分支组织与复杂度 | 网络重塑和疾病组结构比较 | 只能计算标签图的节点代理，不能把二维交叉当解剖分叉 |
| Fractal dimension | 选定尺度范围内的空间填充/复杂程度 | 青光眼、DR、认知及神经血管研究 | 可计算，但对尺度、裁切和图像质量敏感，不能独立证明血管生物学改变 |
| Fine/medium/large strata | 特定数字尺度下不同宽度结构的贡献 | 分解总体表型偏差来自哪里 | 可用训练标签固定分层；“细”不是临床毛细血管类别 |

研究用途依据：[L02、L05–L10、L12]。表中的当前数据裁决为本文根据 [R05、R10–R13] 的可行性分析。

### 3.3 哪些疾病场景值得关注

**糖尿病视网膜病变。** 前瞻性研究曾分析血管迂曲度、分支几何、管径和分形特征与 DR 新发或进展的关系，支持“网络表型值得测量”，但并不意味着这些指标能替代病灶分级。FIVES 的 DR 类别不足以复现含血糖、病程、严重度和随访结局的研究。[L05]

**青光眼。** UK Biobank 前瞻性研究报告了动脉/静脉骨架密度与分形维度和新发青光眼的关联；另一方面，另一项正常眼压性青光眼/原发开角型青光眼研究并未观察到相同方向的血管几何损害。疾病亚型、指标、样本与研究设计不同，不能要求所有“青光眼”样本都出现低密度。[L06、L07]

**AMD。** 一项小样本新生血管性 AMD 研究探讨基线视网膜血管几何与抗 VEGF 初始治疗反应的关联，属于有前景但需要验证的场景。它既不证明二值血管分割可诊断 AMD，也不把照片中的视网膜血管等同于脉络膜新生血管网络。[L09]

**高血压、心血管与脑血管疾病。** 管径、迂曲度、血管面积在大型队列中用于血压/动脉僵硬度关联和循环死亡、卒中、心肌梗死风险建模。这里对测量的要求是可复现、可校准、可跨人群，而不是掩膜更像训练标签就足够。[L08、L10]

**肾病。** 视网膜与肾脏微血管损害具有研究动机，但不能把“管径改变可筛查肾功能下降”作为既定事实。参与者级荟萃分析发现口径与肾功能降低的关联很有限，说明疾病故事必须接受阴性证据。[L11]

**神经/认知疾病。** 横断面研究报告较稀疏的动静脉分形网络与认知障碍相关；这属于关联研究，不证明血管分割能够诊断痴呆或识别个体未来风险。FIVES 没有认知、MRI 或神经结局，当前只能借此解释测量可靠性的远期意义。[L12]

### 3.4 本项目最合适的医学定位

**医学影像定量测量的分析有效性研究。** 面向需要比较不同疾病背景下血管表型的研究人员，检验自动分割是否成为一个有偏的测量环节。

这比“提高细血管 Recall”更接近真实需求，也比“改善临床诊断”更符合当前证据。它仍需要先证明本地失败模式存在，而不能仅凭文献存在相关疾病就宣布选题成立。

## 4. 八个主要临床/科研痛点

以下是待验证的问题，不是对当前模型的定罪。

| 编号 | 痛点的临床/科研表述 | 不是哪一种算法口号 | 当前优先级 |
|---|---|---|---|
| RQ1 | 自动测量的血管网络延伸程度偏离参考，使表型定量不可靠 | 不是“提高 clDice” | 最高 |
| RQ2 | 疾病组之间的测量偏差不同，使表型组间比较混入 AI 偏差 | 不是“哪个病种 Dice 最低” | 高；并入主线 |
| RQ3 | 成像质量变化引起的测量漂移，被误解成血管生物学变化 | 不是“低质量图刷分” | 高；次选 |
| RQ4 | 错误连接/断裂改变管段身份，使分叉和迂曲度测量失真 | 不是“连接越多越好” | 高风险 |
| RQ5 | 边界偏移和选择性漏检改变口径分布，产生虚假的血管粗细差异 | 不是“粗血管边界更平滑” | 中 |
| RQ6 | 参考标签自身不稳定或不可见，导致模型比较超过证据可辨认能力 | 不是“AI 能补出隐藏真血管” | 限定性审计 |
| RQ7 | 工作流不知道哪些自动测量不可信，人工复核资源无法有效分配 | 不是“输出一个置信度” | 条件性扩展 |
| RQ8 | 病灶被当成血管或遮蔽血管，使局部和总体表型被污染 | 不是“给 C1 寻找病灶解释” | 当前不做主线 |

## 5. 每个痛点的完整因果链

### RQ1：网络延伸程度测不准

医学研究需要比较血管网络的空间延伸和稀疏程度 → 工作流从二值分割提取骨架/长度 → 漏掉面积不大但延伸较长的可见细支，或增加伪血管 → 面积重叠分数对这些错误的权重可能不足 → AI 可在模型选择、监督或采样处改变这些错误 → 以预测和标签的骨架密度/长度误差为终点 → 副作用是增粗、伪分支和错误数量补偿。**必须同时约束错误位置与误检负担，不能只配平总长度。**

### RQ2：组间生物学比较被测量偏差污染

研究者需要比较疾病组的血管表型 → 同一自动流程处理不同背景图像 → 不同疾病背景或其相关图像质量导致不同方向的测量误差 → 每组平均 Dice 不能指出差异被夸大还是抵消 → AI 可通过统一校准、误差导向采样或稳健训练改善最差组误差 → 终点是组间误差差异以及 AI 组间对比相对标签对比的偏移 → 副作用是过拟合少数组、抹平真实疾病差异，或把标签偏差当作模型问题。[L01、L13]

### RQ3：把成像漂移当作生物学变化

研究者希望跨照片或随访比较表型 → 图像亮度、颜色、模糊和对比度发生变化 → 分割改变导致同一结构的表型漂移 → 单次 Dice 和总体均值没有衡量这种不稳定性 → AI 可在增强、预测一致性或测量可信度判定处干预 → 终点是配对扰动前后的漂移及相对原始标签的绝对误差 → 副作用是模型输出过于恒定、对真实病变变化不敏感，或剔除过多患者。[L03、L04、L13]

### RQ4：管段身份错误，而不只是像素错误

迂曲度和分叉测量需要定义完整路径 → 骨架图被分解成节点和边 → 很小的断点使一条长血管变成几条短段，假桥又将两条独立血管混合 → Dice 几乎不变，但“这条管段是谁”已经变化 → AI 可在局部判别或结构监督处干预 → 终点是匹配管段的测量误差、可匹配覆盖率及错误连接率 → 副作用是把真实二维交叉误当成应连接的分叉，或违背标签不补画规则。[L01、L02]

### RQ5：宽度组成被选择性筛选

管径分布用于描述血管表型 → 在分割内部估计局部宽度 → 一像素边界偏移对小血管影响大；若细血管漏掉，剩余血管的平均宽度会“被动变大” → 全局 Dice 与平均管径不能区分边界偏差和漏检选择偏差 → AI 可通过边界/直径平衡监督或约束选阈值干预 → 终点是固定参考支持区域上的宽度误差、分布距离及覆盖率 → 副作用是牺牲细支检出以获得漂亮的匹配管段误差。[L02、L10、L16]

### RQ6：参考标准无法支撑精细优劣判断

研究者需要可靠地比较模型 → 使用公开人工标签作为参考 → 低对比结构、标签缺口和同图不同标签产生参考不确定性 → 模型差异小于标签/提取规则的变化时，单一 Dice 或 MAE 排名容易被过度解读 → AI 可辅助定位不确定区域和做多参考敏感性分析 → 终点是参考改变引起的表型跨度和模型排名稳定性 → 副作用是按有利标签挑结果，或把标签差异包装为“真正血管”。[L01；R05]

### RQ7：不知道何时不应该相信自动测量

人工复核时间有限 → 系统给出每幅图的测量结果，但没有有效失败提示 → 严重错误混入队列，或所有图都需要人工检查 → 平均 Dice/平均误差不能告诉研究者把复核时间花在哪里 → AI 可增加独立的测量风险估计与转人工规则 → 终点是固定复核预算下的高误差病例检出和保留样本测量误差 → 副作用是优先拒绝疾病组和低质量组，制造选择偏差。当前只能模拟转人工，不能证明医生时间节省。[L02–L04]

### RQ8：病灶污染了血管测量

疾病图像中的血管表型需要与病灶表现区分 → 血管分割直接处理包含局部病变的照片 → 局部病灶可能被吸入掩膜，或使可见血管断续 → 全图 Dice 会稀释局部问题，也不能指出病灶是哪一种 → AI 可做病灶条件的局部判别或多任务监督 → 终点应是病灶邻域内的血管测量误差及全图偏差传播 → 副作用是把真实异常血管当病灶移除。**FIVES 缺少病灶级真值，本次只能提出假设，不能归因。**[L01；R05]

## 6. 分割误差如何传播到下游医学测量

### 6.1 先把面积密度和长度密度分开

设固定有效区域为 $F$，人工标签为 $Y$，模型概率为 $p$，全局阈值为 $t$，阈值结果为 $P_t$。所有测量都使用同一个预先固定的有效区域。

$$
P_t=\{x\in F:p(x)\geq t\},\qquad
D(V)=\frac{|V\cap F|}{|F|}.
$$

面积密度误差有一个直接的恒等式：

$$
D(P_t)-D(Y)=\frac{FP-FN}{|F|}.
$$

因此，大量误检和漏检可能恰好抵消，得到很小的密度误差。**密度误差小不等于分割位置正确。** 反过来，固定面积的错误重连也可以保持密度不变，却破坏结构测量。

当单图的 Precision 和 Recall 都有定义且真阳性非零时：

$$
\frac{|P_t|}{|Y|}=\frac{\mathrm{Recall}}{\mathrm{Precision}}.
$$

这使原始逐图指标可以支持一个低成本面积比例检查；但必须逐图计算，**不能把总体平均 Recall 除以总体平均 Precision 当成平均面积偏差**。当前报告没有据宏平均反推未观测的疾病密度结果。

### 6.2 本报告建议的主要测量定义

定义固定版本的 Zhang 骨架算子为 $S$：

$$
V_{\mathrm{S}}(V)=\frac{|S(V\cap F)|}{|F|}.
$$

这是**离散骨架像素密度**，可作为可见血管网络长度密度的数字代理。它是栅格计数比值，不是有物理单位的长度密度；它受方向和数字化规则影响。因此主要分析固定原始分辨率和同一算法，不跨尺度直接混算。

主要终点建议冻结为逐图绝对相对误差的宏平均：

$$
E_{\mathrm{S},i}=\frac{\left|V_{\mathrm{S}}(P_i)-V_{\mathrm{S}}(Y_i)\right|}{V_{\mathrm{S}}(Y_i)},\qquad
\mathrm{MARE}_{\mathrm{S}}=\frac{1}{n}\sum_{i=1}^{n}E_{\mathrm{S},i}.
$$

此分母只对非空且骨架非空的参考成立。当前 118 图主分析满足原本非空资格；单列空标签不能偷偷用一个小常数制造有限的“相对误差”，而应报告预测前景/骨架负担及不可定义状态。

**为什么选择它而不直接以所有 morphology 的平均分作为主要终点？** 它与网络延伸的需求相关，利用现有骨架实现，易于独立复算，也避免在许多指标中事后选择改善最大的一个。局限是不能约束管段身份和几何长度；因此必须有结构和误检保护指标。

### 6.3 几何长度和数字管径的次要定义

几何长度另行从骨架图计算，水平/竖直边权为 1，对角边权为 $\sqrt{2}$。构图必须去除具有水平—竖直替代路径的冗余对角边，处理节点簇，并通过直线、斜线、圆环和 Y 形合成图测试；不能简单把全部八邻接边相加。该结果以**像素长度**为单位，除以 FOV 像素面积后是像素尺度的长度密度，不是 $\mathrm{mm}^{-1}$。

$$
L(V)=\sum_{e\in E(S(V))}w_e,\qquad w_e\in\{1,\sqrt{2}\}.
$$

局部宽度可以用距离变换构造代理：

$$
w(x)=2\,\mathrm{EDT}(V)(x),\qquad x\in S(V).
$$

该数值受到像素中心约定、离散边界、分叉与交叉影响，不是精确的管腔直径。尤其在窄线中，整数距离变换与人工“宽几个像素”的定义也可能不同，必须用合成管道校验。

### 6.4 典型误差与传播方向

| 分割错误 | 面积密度 | 骨架密度/长度 | 分叉/迂曲度 | 宽度分布 | 判读重点 |
|---|---|---|---|---|---|
| 细支整段漏检 | 通常下降，可能幅度不大 | 可明显下降 | 分支数下降；管段选择改变 | 剩余宽度均值可能上升 | 面积权重与长度权重不同 |
| 血管增粗 | 上升 | 中心线近似不变，也可能生伪枝 | 节点区域变化 | 上移 | 细骨架召回提高不自动说明找回了更多真实路径 |
| 小范围断裂 | 下降较小 | 少量下降 | 管段断成多个；端点增加 | 局部改变 | 结构后果可能大于像素损失 |
| 假连接 | 上升较小 | 增加少量 | 路径身份、环和节点可能突变 | 交汇处局部变大 | 不能用“更连通”替代“更正确” |
| 细长伪影 | 上升 | 可能增加很多 | 伪分支、伪路径 | 人造细端尾部 | 配平总长度可能作弊 |
| 病灶块被吸入 | 可能明显上升 | 骨架化后形状不可预测 | 出现伪节点 | 尾部异常增粗 | 没有病灶标签不能确定因果来源 |
| 裁切/FOV 不一致 | 任意 | 任意 | 边界端点和短段增多 | 选择性偏移 | 先修测量流程，再谈新模型 |

方向为几何推理，不是声称每幅 FIVES 图均发生这些现象。多个错误同时存在时可以相互抵消。

### 6.5 分叉、迂曲度、CRAE/CRVE 的可行性边界

分叉节点应由邻近高阶节点像素聚类形成，不能把每个度数大于等于 3 的像素都算成一个分叉。二值照片中的动静脉交叉也不等于解剖分叉。当前最多研究**标签图节点代理**。

最简单的路径迂曲度是弧长与端点直线距离之比，但缺失一半路径、只在幸存的容易段上计算，会得到虚假的“误差很小”。应同时报告固定参考管段的匹配率、无法测量比例和匹配部分误差，不能把未匹配段排除后宣称完整可靠。

CRAE/CRVE 通常需要动静脉身份、视盘相关区域和标准化选管/合并步骤；总体二值掩膜的 EDT 均值不能替代它们。当前 FIVES 没有对应人工参考，本轮不把 CRAE/CRVE/AVR 作为主终点。[L02]

## 7. 传统像素指标的局限：不能把反例当成本地结论

Dice 是前景重叠的汇总，Precision 是预测前景的纯度，AP 是阈值扫描下的排序表现。它们各自有用，但不直接衡量“提取的血管网络长度偏差是多少”。clDice 使用骨架与掩膜的相互覆盖，仍然是标签相关的结构代理，不是临床结局，也不是逐条血管身份的证书。[L14、L15；R11]

**高 Dice 仍可能对应某些形态误差，只是逻辑可能；当前 M0/M1 是否如此，还需要 Stage A。** 不允许把人为制造的一像素断点反例当成模型在 FIVES 上已经普遍失败的证据。

已有研究也提醒相反方向：特定形态统计量可以在不很高的像素重叠下保持较好的总体一致性。AutoMorph 和重测研究已经使“比较 Dice 与 morphology”成为一个已有研究方向；本项目需要贡献更具体的误差分解、疾病/质量条件下的偏差证据和经过控制的干预，而不是宣称首次发现指标不一致。[L02–L04]

建议报告三个不同问题：

1. **关联：** Dice 较低的图，测量误差是否一般更高？
2. **决策一致性：** 依据 Dice 选出的模型/工作点，是否也是满足保护指标时测量误差最小的方案？
3. **绝对可用性：** 即使两者高度相关，误差是否仍超过本项目预先规定的技术容许范围？

仅有很高的相关系数，不能证明测量可替代，也不能独自触发 STOP。[L17]

## 8. 疾病亚组：重点研究 measurement bias

### 8.1 不比较“谁分低”，而比较“谁被量错”

对每个表型 $m$ 和每张图像：

$$
e_i=m(P_i)-m(Y_i),\qquad
r_i=\frac{m(P_i)-m(Y_i)}{m(Y_i)}.
$$

疾病组与正常组的 AI 表型差异相对标签差异的偏移，恰好等于两组平均测量误差之差：

$$
B_{d,N}=\left(\bar m_{\mathrm{AI},d}-\bar m_{\mathrm{AI},N}\right)
-\left(\bar m_{\mathrm{GT},d}-\bar m_{\mathrm{GT},N}\right)
=\bar e_d-\bar e_N.
$$

这个恒等式使“疾病亚组”从排行榜变成一个可解释的科研问题：**AI 流程是否把参考中的组间差异放大、削弱甚至翻转？** 当标签组间差异接近零时，不使用“偏差占疾病效应的百分比”这一不稳定比例；报告原单位差值和按训练集尺度标准化后的偏差。

### 8.2 必须展示的结果

每个疾病组展示参考表型分布、AI 表型分布、带符号误差、绝对误差和配对散点，另外展示疾病×IC/Blur/LC 的样本计数。对 A/D/G 相对 N 的三项对比提前登记，使用同一套主要终点，不在结果出现后改为最有利的二分类。

118 图开发集 A=28、D=30、G=30、N=30；现有局部冲突在 G 和 D 更高，但这不证明血管表型偏差已经更高，也不证明疾病本身造成错误。[R01、R02]

### 8.3 质量混杂和共同支持

首先做描述性分层，其次才使用低自由度模型，例如：

$$
e_i=\beta_0+\sum_{d\ne N}\beta_d I(D_i=d)
+\gamma_1 IC_i+\gamma_2 Blur_i+\gamma_3 LC_i+\eta\,m(Y_i)+\epsilon_i.
$$

这只是误差关联模型，不是疾病因果模型。报告稳健区间，并检查共线性、组间共同支持和小单元格。如果某个质量状态只出现在一个病种，不以回归系数宣称已经分离“疾病效应”和“质量效应”。年龄、性别、病程、严重度等未提供信息，不能靠增加模型复杂度补出来。

**禁止做法：** 强制四病种的预测密度均值相等。要减少的是各组 AI−GT 误差，不是消除标签中本来可能存在的疾病差异。

### 8.4 统计单位和测试集保护

主统计单位是图像；已知同图重复应按原图内容组处理，而不是把重复标注看成独立患者。未知左右眼相关性无法通过图像 bootstrap 消除，因此区间仅支持当前图像级协议下的判断。

正式测试保留官方 200 图的基准口径，同时对已知测试重复组采用聚类重采样，并给出去重权重敏感性分析。既不把 200 图写成 200 个独立患者，也不为获得更好的成绩临时删除重复组。每个种子的结果单列；三个种子不是把 118 张图变成 354 个独立病例。

## 9. 当前 M0 / M1 / C1 的重新定位

### M0：像素重叠基线，必须保留

当前正式开发实现使用 FOV 内逐图归一化 BCE 加 Soft Dice，而不是直接沿用旧 `retinal_m0/objectives.py` 中不带 FOV 的历史函数。它优化像素分类和区域重叠；没有明确优化长度、宽度分布或疾病组误差。[R10]

它最适合作为**问题发现的测量仪器基线**，也应是后续任何干预的匹配控制。不能为了突出新主线而丢掉 M0 的原结果。

### M1：已知机制对照，不是默认获胜者

M1 在 M0 上加入标签内膨胀骨架的软召回项。当前 tube 由整图 Zhang 骨架向外膨胀 2 像素后与标签相交得到；主细骨架阈值由 470 图训练骨架半径标定，当前半径阈值为 4.0 原始像素。[R12、R13]

这一项直接鼓励参考中心区域得到较高概率，**没有单独的预测伪骨架惩罚，也不是完整 clDice 损失**。它可帮助检验“增加标签骨架覆盖是否改善下游测量”，但不能由 Recall 提高推导长度、分叉或临床收益。[R12；L15]

**角色：保留为机制实验、普通轻量对照。** 若 Stage A 显示 M1 只增加误检/宽度而没有测量收益，就不再把它当作主线。若它已足够好，允许课程项目止步于可靠复现与适用条件分析，不强行发明更复杂方法。

### C1：候选局部判别工具，继续暂停

PAIR 比较同一标签弧段的低分前景和邻侧高分背景，SHUFFLE/POOL 用于区分“局部配对”与一般困难排序。它解决的是**局部得分次序冲突**，而不是直接优化血管长度，也没有证明针对某种出血或渗出。[R03、R15]

它只有在以下链条成立时才值得重启：局部排序冲突 → 可定位的错误路径/伪支 → 对预定测量有可观贡献 → 相同曝光的配对干预比一般排序对照更好 → 额外误连接没有恶化。目前这条链未完成，误连接保护指标也尚未完成。[R02、R03]

**裁决：保留代码与历史证据，暂停研究训练；取消其“默认下一方法”的地位。** 6.02% 低于旧 10% 参考值不是单独的科学否定，但也不是继续投入的理由。


## 10. 八个候选 Research Questions：完整候选卡

下列“现有 AI 没解决”专指**本项目尚未证明解决**，不声称全领域没有已有方法。临床动机见第 3–5 节；量化定义见第 6、8 节；所有候选的工期和 Codex 分项评分见第 11–15 节。GPU 预算按 RTX 5080 当前 10k 轨迹锚点估算，不按模型名称想象速度。

### RQ1｜高像素精度是否足以保证可见血管骨架密度测量可靠？

| 项目 | 方案 |
|---|---|
| 临床痛点 | 作为网络稀疏化/延伸程度代理的测量，被分割漏检或伪结构改变 |
| 临床/科研使用场景 | 跨病例、跨疾病的彩色眼底血管定量研究；不是毛细血管灌注监测 |
| 医学后果 | 研究中的网络差异可能被夸大或抵消；无法直接推出诊断错误率 |
| 当前流程缺口 | M0/M1 只完成像素、骨架召回和局部诊断，未核实预测派生的表型误差 |
| 核心假设 | 较高 Dice 仍可能掩盖足够大的骨架密度偏差，且部分偏差可被有针对性的干预减少 |
| AI 干预位置 | 首先是阈值/模型选择；确有剩余问题时才进入训练目标或采样 |
| 可能方法 | 测量导向的全局工作点选择；否则一个空间受约束的骨架数量匹配辅助项，或由误差分解决定的单一监督改动 |
| Primary endpoint | 118 图开发和冻结测试上的 `MARE_S`，即骨架像素密度绝对相对误差宏平均 |
| Secondary endpoints | 几何加权长度误差、面积密度误差、带符号偏差、ICC(A,1)、Bland–Altman、疾病/质量分组误差 |
| Guard metrics | Dice、Precision、AP、每 FOV 误检面积、伪骨架负担；禁止靠错误位置的伪枝配平数量 |
| Stage A：发现 | 复算 M0/M1 的骨架密度和面积密度；分解缺失与额外骨架；检验高 Dice 子集是否仍有实质误差 |
| Stage B：干预 | 先比较固定 0.5、Dice 导向工作点、测量导向工作点；仍不足才新训练 |
| 所需实验 | 测量单元测试；原始逐图配对审计；工作点控制；新方法与 M0/M1 三方法三新种子；独立测试 |
| FIVES 是否足够 | **直接支持标签相对测量有效性；部分支持医学意义。** 不支持真实生理稀疏化、临床风险改善 |
| 额外数据 | 最小闭环不需要；跨来源扩展可用已取得外部数据，但须另验 ROI/尺度/标签规则 |
| GPU/完整训练 | Stage A：0–0.5 h、0 次；条件性课程闭环：16–24 h、10 次新增完整轨迹 |
| 工程修改量 | 新增独立形态评价模块、错误分解与统计；Stage B 最多一个辅助项，不重构 U-Net |
| 实现/实验/统计/临床解释难度 | 2 / 3 / 3 / 3；总体 3。初始 Stage A 实现难度 2 |
| 失败风险 | 中：当前模型的测量误差可能已经很小；数量匹配可能只产生伪枝 |
| 结果可解释性 | 高：改善的是多少测量误差、付出多少误检可以逐图解释 |
| 负结果价值 | 高：证明现有简单流程已足够，或揭示召回收益没有测量收益，均可形成完整课程结论 |
| 新颖性潜力 | 中：一般 morphology 评价已有先例；贡献应是条件性偏差、误差预算和干预证据，不是新 loss 名字 |
| 临床意义/课程可行性 | 临床研究相关性高，临床效用待验证；课程可行性高 |
| Codex/人力 | 5/5；Human workload=Medium，AI leverage=Very High |
| GO | 预定主要测量误差达到第 24 节的技术重要性门槛，且排除测量实现错误后仍存在 |
| HOLD | 相对误差被小分母、标签异常、提取规则敏感性或样本不足主导 |
| STOP | 误差上界低于预定容许区间，或简单工作点已经达到目标；停止新训练而不是停止交付 |

### RQ2｜AI 是否给不同疾病组引入不同方向的血管表型测量偏差？

| 项目 | 方案 |
|---|---|
| 临床痛点 | 研究者观察到的“疾病差异”中混入自动测量系统的条件性偏差 |
| 临床/科研使用场景 | 比较 A/D/G/N 血管表型，或将分割产生的表型输入后续统计模型 |
| 医学后果 | 疾病组差异的方向和幅度可能错误；不能由此断言临床诊断已经改变 |
| 当前流程缺口 | 已有分组 Dice/Recall，但没有分析 `AI−GT` 误差和组间对比偏移 |
| 核心假设 | 某些疾病/质量条件下存在系统性偏差，不能由单一全局平均误差代表 |
| AI 干预位置 | 统一的误差导向校准、训练样本暴露及稳健优化；不默认使用疾病特异阈值 |
| 可能方法 | 优先全局工作点；再考虑限制权重范围的疾病/质量均衡采样；优化误差而不是使四组表型均值相等 |
| Primary endpoint | 三个疾病组对正常组的最大绝对测量偏差差异，`max abs(B_d,N)`；以训练集参考均值标准化，避免近零组间差分母 |
| Secondary endpoints | 每组带符号误差/MAE、最差组 MAE、原始与质量条件下的组间对比、模型间配对改善 |
| Guard metrics | 总体 `MARE_S`、Dice/Precision/AP、各组误检负担；不得损害某一组换取总体公平外观 |
| Stage A：发现 | 同图计算 GT/AI 表型和误差；疾病×质量交叉表；未调整与低自由度调整分析并列 |
| Stage B：干预 | 仅当偏差具有共同支持且并非单图驱动时，检验一种误差导向的全局或采样策略 |
| 所需实验 | 正常组参照的三项预定对比；图像 bootstrap；小样本和已知重复敏感性；新方法多种子 |
| FIVES 是否足够 | **直接验证当前数据上的分组测量偏差；只能部分验证病种条件性原因。** 无法分离全部年龄/严重度/患者因素 |
| 额外数据 | 最小验证不需要；强疾病因果解释需要临床元数据和更好匹配队列 |
| GPU/完整训练 | 最小审计 0–0.25 h、0 次；含一种干预的独立课程路线 12–20 h、7 次 |
| 工程修改量 | 低：复用 RQ1 测量，新增配对统计和分组可视化；训练仅改一种采样/权重策略 |
| 实现/实验/统计/临床解释难度 | 1 / 3 / 4 / 4；总体 3 |
| 失败风险 | 中：质量和疾病缺乏共同支持；某组误差可能由少数图像主导 |
| 结果可解释性 | 高于单纯病种 Dice 表，但因果解释必须保守 |
| 负结果价值 | 高：给出在技术容许范围内的分组偏差上界；“不显著”本身不等于无偏 |
| 新颖性潜力 | 中：条件性测量偏差和组间效应扭曲比再加结构模块更清晰 |
| 临床意义/课程可行性 | 临床研究相关性高；能直接服务课程必做疾病亚组分析 |
| Codex/人力 | 5/5；Human workload=Low–Medium，AI leverage=Very High |
| GO | 预定标准化偏差超过技术门槛，方向在合理敏感性分析中一致，并有足够质量共同支持 |
| HOLD | 某质量状态仅有单一疾病或每格样本极少；仅显示描述性偏差，暂不作稳健训练归因 |
| STOP | 各对比误差上界均足够小，或偏差主要源于无法判定的参考规则，当前数据无法支撑干预 |

### RQ3｜图像质量变化会不会被自动流程误读为血管稀疏化？

| 项目 | 方案 |
|---|---|
| 临床痛点 | 不同采集质量造成假性表型变化，使比较或随访不可靠 |
| 临床/科研使用场景 | 多次拍照、不同曝光/聚焦条件下的自动定量；FIVES 中只能做横断面和合成压力测试 |
| 医学后果 | 同一可见结构可能被测成不同密度；不能把合成变化直接称真实随访失败 |
| 当前流程缺口 | 当前没有成像扰动前后同图表型漂移的冻结测试 |
| 核心假设 | 在温和、仍可辨认的图像改变下，模型的测量漂移超过技术容许范围 |
| AI 干预位置 | 光度增强、成对一致性监督或测量失败提示 |
| 可能方法 | 先用常规增强作为对照；只有剂量匹配后仍有收益，才保留结构特异的增强/一致性方法 |
| Primary endpoint | 同图温和扰动前后骨架密度的绝对相对漂移，按图先汇总，再作图像宏平均 |
| Secondary endpoints | 相对原始 GT 的绝对测量误差、质量分层偏差、FD 漂移、各病种误差变化 |
| Guard metrics | 原始图 `MARE_S`、像素指标、扰动图对 GT 的误差；防止恒定输出“看起来很稳定” |
| Stage A：发现 | 固定模糊、亮度/颜色、对比度三类扰动与剂量；同图多版本；FOV 保持原始图定义 |
| Stage B：干预 | 一种常规增强对照 vs 一种有明确机制的改动，剂量和训练曝光相同 |
| 所需实验 | 原生质量×疾病审计；配对压力测试；多种子训练；自然低质量图独立验证 |
| FIVES 是否足够 | **直接支持横断面质量误差；部分支持配对鲁棒性。** 不支持真实重测重复性、长期随访精度 |
| 额外数据 | 最小方案不需要；真实临床重复性需同眼重复采集或公开重测数据 |
| GPU/完整训练 | 方向性 0.5–2 h、0 次；课程干预 18–30 h、10 次 |
| 工程修改量 | 中：扰动生成、配对推理和采样/增强对照；不新增网络主干 |
| 实现/实验/统计/临床解释难度 | 2 / 3 / 3 / 4；总体 3 |
| 失败风险 | 中：合成失真不代表真实质量，过强扰动不再有可信可见性参考 |
| 结果可解释性 | 高：配对设计固定同一结构，但只对指定扰动有效 |
| 负结果价值 | 高：识别稳定区间和失败剂量边界，避免无根据增强 |
| 新颖性潜力 | 中：增强本身常见；“测量漂移—剂量—自然质量验证”才有实证贡献 |
| 临床意义/课程可行性 | 有明确工作流意义；适合作为 RQ1 的压力测试或主线备选 |
| Codex/人力 | 4/5；Human workload=Medium，AI leverage=High |
| GO | 温和剂量下漂移超过预定门槛，并在自然低质量图有相容方向证据 |
| HOLD | 仅在极强模糊/不可辨识图出现问题，或原生质量与合成失真方向不一致 |
| STOP | 温和扰动已稳定，或常规增强充分解决；停止复杂的一致性/特异增强方法 |

### RQ4｜错误的路径与节点会不会使迂曲度和分支测量失效？

| 项目 | 方案 |
|---|---|
| 临床痛点 | 管段身份不正确，后续路径级测量不能解释为同一条血管的几何 |
| 临床/科研使用场景 | 管段迂曲度、分支复杂度和局部网络分析 |
| 医学后果 | 伪造或遗漏分支，改变被纳入测量的管段；不自动等于实际解剖拓扑损害 |
| 当前流程缺口 | 局部路径通过率已有，但缺乏误连接率、稳定管段匹配及下游几何终点 |
| 核心假设 | 少量像素的拓扑错误对固定参考管段的可测量性具有超比例影响 |
| AI 干预位置 | 结构监督、局部判别、测量前的可测量性拒绝规则 |
| 可能方法 | 普通结构损失先做对照；仅在局部排序机制确实主导时考虑 C1，并保留 SHUFFLE/POOL 控制 |
| Primary endpoint | 固定参考管段中无法可靠匹配或出现错误路径连接的比例；先定义标签相对“测量失败” |
| Secondary endpoints | 匹配段弧弦比误差、加权长度误差、节点簇数量偏差、局部误桥/断裂 |
| Guard metrics | 全图误检、伪桥率、可匹配覆盖率、面积与骨架测量误差；不得只报幸存管段 |
| Stage A：发现 | 在合成图和现有路径中检验图构造稳定性；再检查真实预测的管段测量失败 |
| Stage B：干预 | 仅图身份可定义且问题足够大时，做结构控制和一个局部方法 |
| 所需实验 | 交叉/分叉/短枝/边缘单元测试；图像级汇总；路径错误审查；至少三方法三种子 |
| FIVES 是否足够 | **部分支持。** 二维二值标签不能确定真实动静脉交叉或完整解剖网络 |
| 额外数据 | 标签相对研究可不新增；真实拓扑评价需更强参考或专家复核 |
| GPU/完整训练 | 方向性 0–1 h、0 次；有限课程图代理研究 22–40 h、10–13 次 |
| 工程修改量 | 高：图重建、节点聚类、路径匹配、误桥检测，比写 loss 难 |
| 实现/实验/统计/临床解释难度 | 4 / 4 / 4 / 5；总体 4 |
| 失败风险 | 高：指标本身不稳定、交叉歧义、选择偏差；不能用更多训练弥补 |
| 结果可解释性 | 条件性中等；只限能可靠定义的参考管段 |
| 负结果价值 | 中：可揭示公开二值标签不适合某些拓扑主张，但须把失败与实现错误区分 |
| 新颖性潜力 | 中高；对测量身份失败的严格处理比拓扑分数增量更有价值 |
| 临床意义/课程可行性 | 潜在价值高；当前课程不宜作为第一主线 |
| Codex/人力 | 3/5；Human workload=High，AI leverage=High，但核查负担大 |
| GO | 固定规则在代表性参考管段上稳定可用，且路径失败贡献显著、误桥评价可实现 |
| HOLD | 稳定可匹配覆盖不足、两种合理构图规则结论翻转，或主要集中在交叉歧义 |
| STOP | 无法建立可信的标签相对路径身份；不能靠“多连一些”挽救 |

### RQ5｜分割是否系统性扭曲血管宽度分布，而非仅漏掉一些像素？

| 项目 | 方案 |
|---|---|
| 临床痛点 | 测到的血管粗细组成被边界偏移和细支选择性遗漏改变 |
| 临床/科研使用场景 | 数字管径分布、不同病种/质量下的宽度表型研究 |

| 当前流程缺口 | 已有 GT 半径图，但没有完整预测宽度测量、匹配支持及选择偏差分解 |
| 核心假设 | M1 等召回改动可能同时改变边界和纳入测量的血管组成，使平均宽度出现混合偏差 |
| AI 干预位置 | 全局阈值、边界/直径平衡目标或测量分层 |

| Primary endpoint | 固定 GT 可匹配管段上局部宽度代理的 MAE；必须同时满足非劣的匹配覆盖率保护条件 |
| Secondary endpoints | 完整预测与 GT 宽度分布距离、分位数误差、细/中/粗分层误差、未匹配长度比例 |
| Guard metrics | 骨架密度误差、细支覆盖率、Precision/AP；不能删除难测血管降低管径误差 |
| Stage A：发现 | 同时分解同一支持区域的边界偏移和因漏检造成的分布选择偏差 |
| Stage B：干预 | 在同工作点规则下检验一个宽度敏感目标；全图推理不增加模块 |
| 所需实验 | 合成不同宽度直管测试、节点/边界排除、支持匹配与未匹配报告、多种子 |
| FIVES 是否足够 | **直接支持数字宽度代理，部分支持医学口径研究。** 不足以验证 CRAE/CRVE 或真实微米尺度 |
| 额外数据 | 最小闭环不需要；物理口径研究需尺度标定、A/V、视盘及规范管段参考 |
| GPU/完整训练 | 方向性 0–0.5 h、0 次；课程闭环 14–24 h、7–10 次 |
| 工程修改量 | 中：预测 EDT、参考匹配、分布统计和一个轻量干预 |
| 实现/实验/统计/临床解释难度 | 3 / 3 / 3 / 4；总体 3 |
| 失败风险 | 中高：数字宽度与真实血管口径的概念距离较大；匹配选择偏差难处理 |
| 结果可解释性 | 对像素代理较高，对真实临床管径有限 |
| 负结果价值 | 高：可判断召回改动究竟是覆盖收益还是边界膨胀 |
| 新颖性潜力 | 中低：直径平衡方法已有；系统误差分解才可能有新增贡献 |
| 临床意义/课程可行性 | 适合作为 RQ1 的机制分析，不宜直接包装成临床口径测量突破 |
| Codex/人力 | 4/5；Human workload=Medium，AI leverage=High |
| GO | 宽度误差跨代表性图像稳定存在，且不是匹配率改变造成的表面现象 |
| HOLD | 不同合理宽度定义产生相反结论，或只有少数可匹配粗血管 |
| STOP | 匹配覆盖无法维持，或误差低于数字化不确定性；不继续临床口径主张 |

### RQ6｜参考标签的不确定性是否足以改变模型的形态测量排名？

| 项目 | 方案 |
|---|---|

## 13. GPU 成本、完整训练次数与资源不确定性

### 13.1 实测锚点

M1 在 RTX 5080 上 10k 训练约 41.56 分钟，加四次完整验证和登记等开销，总窗口约 53.28 分钟；M0 同预算训练约 43.56 分钟，四次验证约 11.94 分钟。以约 **1 GPU-hour/10k 匹配轨迹**作为现有方法的排期锚点是有依据的，不是所有新方法的保证。[R01]

4070 的缓存短程 M1 为约 0.246 秒/步，PAIR 约 0.310 秒/步；这是短程完整更新循环，未证明连续 10k 热稳定性。118 图两模型复核实际占机约 13.45 分钟，包含此次进程内工作；新形态指标的 CPU 时间需另测。[R02、R04]

### 13.2 首选研究的 10 条新增轨迹如何组成

| 工作 | 新完整轨迹 | GPU 规划 | 用途 |
|---|---:|---:|---|
| Stage A 既有概率/模型审计 | 0 | 0–0.5 h | 证明问题存在 |
| 新候选短程 smoke/profile | 0 | 0.5–1.5 h | 梯度、数值、速度、资源与退化行为；不宣称有效 |
| 一个候选的完整开发轨迹 | 1 | 1–2 h | 确认具有方向性、冻结方法；不无限调参 |
| 正式 M0/M1/候选 × 3 个新种子 | 9 | 9–14 h | 以相同数据、步数、工作点规则和输入曝光比较 |
| 冻结测试推理、归档、失败储备 | 0 | 余量至总 16–24 h | 包含必要的额外推理与有限失败，不再隐藏重跑 |
| **合计** | **10** | **16–24 h** | 只在 Stage A 和干预可行性均 GO 后使用 |

7 条轨迹的独立双方法路线对应 1 条开发轨迹加 2 方法×3 新种子；10 条对应 1 条开发加 3 方法×3 新种子。若自定义干预还需要增加普通结构基准或关键消融，每新增一个三种子方法，通常再加 3 条完整轨迹和约 4–7 GPU-hours 的规划余量，须重新审批。10 条预算是课程级最小闭环，不是算法新颖性的充分验证承诺。

现有 seed=2026 两条轨迹作为发现集证据保留，不计入“新增 10 条”，也不伪装成依据新终点前瞻性预注册的结果。新种子仍复用同一图像划分，不解决患者映射缺失。

若 Stage A 显示**只改工作点已经足够**，上述新训练矩阵取消。项目可交付“测量导向选择”的零新增训练路线，或只做少量新的基线重复检验稳定性；两者必须如实报告不同证据强度。

### 13.3 不能被忽略的非 GPU 成本

整图骨架、距离变换、路径图、ICC/重采样主要占 CPU 和磁盘。初始形态审计预留 **2–8 CPU 占用小时**；具体取决于并发和是否重复载入 2048×2048 概率图。不要让 GPU 进程等待 CPU 数小时再把它写成“零算力”。

236 张 2048×2048 的 FP32 概率数组，未压缩约 3.96 GB；九套模型的测试概率和不同阈值二值结果会增加磁盘负担。优先一次读概率、顺序评价阈值、逐图缓存派生结果，避免重复保存全部中间图。缓存目录是派生资产，必须有版本和哈希。[R08；数组大小为本文按尺寸计算]

若新损失需要预测端软骨架，其成本可能明显高于现有 GT 预计算 Skeleton Recall。先实测 500 步；超出资源约束时优先简化目标或取消方法，不悄悄减小有效 batch、改变裁块曝光后仍称完全匹配。

## 14. Codex / AI 编程代理辅助程度

## 18. Quick Win：先把“疾病差异”拆成参考差异与测量误差

优先建立一张每图一行的表：`image_key / disease / IC / Blur / LC / checkpoint / threshold / FOV / GT_measurement / AI_measurement / signed_error / absolute_error`。

最先计算面积密度，其次骨架密度。只做这一步，就能够把“某疾病组 Dice 低”转化成“这一组被系统性低估、误差变大，还是其实没有明显测量偏差”。不需要先做新的 loss，也不需要疾病分类器。

最小价值不是必然发现偏差，而是**消除当前最关键的未知量**。若四组的误差已经很小，则省下一轮没有必要的模型训练；若偏差只存在于低质量图，则转向 RQ3；若误差来自增粗而非长度损失，则转向 RQ5 的轻量诊断。

## 19. Main Study：有条件的测量导向分割

课程报告的主链条建议改为：

**医学研究需要可信表型 → 自动分割的测量误差审计 → 明确误差机制 → 工作点控制 → 必要时单一训练干预 → 测量改善与误检代价 → 疾病/质量验证。**

这条路线允许三种同样合格的科学结果：发现无需新方法；发现简单选择规则足以解决；发现必须改变监督且得到稳定增益。只有第三种才需要完成“新损失”部分，不能把第三种预先设为唯一成功方式。

在现有证据下，不建议把所有形态指标都同时作为主要终点。**一个主要终点、两个关键测量次要终点、有限保护指标**，更容易在课程时间内完成可信闭环。

## 20. High Risk / High Reward：路径身份与拓扑测量

RQ4 的上限在于触及“哪些数字还能解释为同一条血管”的问题，潜在科学价值高于只加一个拓扑损失。然而当前最难的不是模型，而是参考管段、二维交叉和误桥的定义。

只批准 **4–6 人工日、0–0.5 GPU-hours、0 次新训练** 的可定义性检查。若大部分参考管段无法稳定匹配，或不同合理图构造规则产生完全不同的结论，就立即停止以路径级指标为主的训练；保留它作为“为什么公开二值标签不支持某些拓扑主张”的限制分析。

C1 的重启需经过 RQ4 的因果链，不以“已写了代码”作为通行证。

## 21. Future Work：真正需要新增临床证据的方向

未来扩展优先顺序是：**独立专家参考/重测采集 → A/V 与视盘相关口径测量 → 可靠局部病灶参考 → 临床结局或决策效用验证**。

RQ6 的关键新增不是更大网络，而是明确标注者、复标规则和可见性；RQ8 的关键新增不是多一个 decoder，而是病灶与血管局部参考能否同时可信。FIVES 的四种疾病标签不能替代这些信息。

真实物理口径还需要标定或可说明的放大率处理；真实毛细血管/灌注问题需要适合的成像与参考，不可从普通彩色照片的标签骨架直接推出。

## 22. 首选研究问题与贡献声明

### 最推荐的研究问题

**在跨疾病彩色眼底定量研究中，常规 AI 分割是否因可见细血管漏检和伪结构而造成骨架密度测量偏差，以及能否在不放大误检的条件下，通过测量导向选择或针对性监督减少这种偏差？**

**临床痛点：** 研究人员把自动分割当作测量工具，却不清楚其输出是否因疾病背景或质量而系统性偏移。

**AI 的真正目标：** 降低自动表型与固定参考之间的测量误差；控制错误位置、误检和最差组代价，而不是尽可能多地预测血管像素。

**为什么不是简单追求 Dice：** 医学研究最终使用的是测量值；只要某个更高 Dice 的方法没有减少预定表型误差，就不能仅凭像素指标宣称它更适合该测量用途。反之，Dice 略降也不自动构成医学进步，必须通过保护指标与独立验证。

**可声称的贡献：** 在冻结的 FIVES 图像级协议中，给出可复现的血管表型误差审计、疾病/质量条件性偏差分解，以及一个由真实失败模式驱动的受约束干预或可信负结果。

**不可声称的贡献：** 首次发现 Dice 不等于临床价值；恢复真实毛细血管；改善疾病诊断或患者结局；患者独立泛化；把所有少量 loss 组合称原创。[L02–L04、L14–L16]

## 23. 最小问题发现实验：Stage A 操作规格

### A0. 先恢复“能复算”的资产，而不是只看汇总表

读取当前 release 的 118 图清单、GT、FOV、原生质量字段、M0/M1 的接受检查点和相应概率。若本地缓存不存在，用原图和已有模型重推；不在此次任务里凭 `.runtime` 路径假定它们已经可访问。首次运行输出文件存在性、数据/标签/检查点哈希及软件版本。[R08]

固定同一推理实现和 batch，保持阈值 0.5，不混合历史 batch=8 的配置描述与最新本地 batch=2 的复核口径。先确认重建的像素指标与相应版本的已接受结果相容；数值差异必须解释，不用更好看的版本替换。[R04、R07、R14]

### A1. 冻结一页协议

冻结主要终点 `MARE_S`；次要测量为面积密度和加权长度；细骨架仍用当前训练标定半径阈值 4.0 像素作为机制分层。新增中/粗分层只根据训练标签确定，避免按预测自身的宽度分类而改变分母。[R13]

冻结 FOV、骨架算法和软件版本、空集行为、疾病对比、质量分析、主要置信区间口径、高 Dice 子集阈值 0.90 及病例展示规则。**高 Dice 子集用于验证代理指标局限，不代替全 118 图主分析。**

### A2. 测量单元测试

至少验证：水平线、45° 斜线、圆环、Y 形分支、平行线、小断点、假桥、增粗管道、孤立伪枝、空图、全前景、FOV 边界管道。测试目的是验证量和程序，不是证明真实模型出现这些错误。

面积密度与 `FP−FN` 恒等式应逐图成立；同一输入重复提取应一致；更换裁块读取顺序不影响整图测量。由另一组员独立用二值计数复算面积和骨架密度，不让同一函数自我验证。

### A3. 零训练计算

对 M0/M1 全部 118 图计算 GT 和 prediction 派生的面积密度、骨架密度、加权长度，保存**原始测量值**而非只保存误差。输出图像级 MAE、MARE、带符号偏差、中位数、四分位数和尾部误差。

同时报告漏检参考骨架、预测端额外骨架、宽度代理变化。空间机制分解必须承认中心线有轻微偏移，预先固定 0/1/2 像素容差作为敏感性，而非只展示最有利容差。

### A4. 检验像素选择是否与测量目标冲突

画 Dice 与主要测量误差的逐图关系；比较 M1−M0 的 Dice 变化和误差变化是否一致。所有图像参与主要比较；高 Dice 区间另外标注，不按事后失败程度定义新子集。

病例展示预先采用四类：高 Dice/低测量误差、高 Dice/高测量误差、低 Dice/低测量误差、低 Dice/高测量误差，各取固定规则下的一至两张；另展示 G 组已知困难图，但不让它代表整个病种。

### A5. 疾病与质量分析

按第 8 节输出误差而不只是 Dice；展示质量交叉表及小样本警告。先用图像级配对重采样给区间；所有候选共享一份原始结果表，防止三个人各自改动样本分母。

### A6. 裁决文件

## 24. GO / HOLD / STOP：提前限定继续的理由

### 24.1 这些不是临床 MCID

FIVES 没有临床结局，也没有本任务可用的“某个骨架误差相当于多少临床损害”的标准。以下数值是为了限制训练投入而拟定的**课程技术决策门槛**，须在看到新形态结果之前由项目组批准。不得在结果出现后微调门槛来保住某个候选。

### 24.2 首选 RQ1 的主门

| 裁决 | 建议规则 | 行动 |
|---|---|---|
| GO：问题存在 | M0 的 `MARE_S` 点估计至少 5%，图像级 95% 区间下限超过 3%；测量测试通过，误差分解显示真实预测—标签差异，而非实现故障 | 批准工作点控制；尚不自动批准训练 |
| HOLD：大小未明 | 区间跨越 3%–5% 决策区间；少数异常图主导；或骨架/ROI 敏感性改变结论 | 检查数据和测量，报告不确定性；不得直接加 loss |
| STOP：无足够问题 | 区间上限低于 3%，且未发现预定疾病/质量偏差门触发 | 停止“必须新训测量模型”的分支；交付可靠性/负结果 |
| STOP：问题已被简单方法解决 | 受保护的统一工作点使误差达到技术目标，新训练没有明确额外目的 | 保留工作点方法，取消新损失训练 |

5%/3% 不意味着生理改变达到临床显著程度；如果小组认为项目应用场景需要更严格测量，应在首次计算前重新规定，而不是借助测试结果反向定义。

RQ1 的总体误差较小、但 RQ2 的条件性偏差较大时，可以**登记转向 RQ2**，而不是把 RQ1 事后改成“最差组指标”。同理，只有温和质量扰动触发时，登记转向 RQ3。

### 24.3 各候选的额外门槛

| 候选 | GO：问题和数据足以继续 | HOLD：仍需查清 | STOP：当前不再投入 |
|---|---|---|---|
| RQ2 | 最大组间偏差差异达到训练参考均值的 3%，区间排除 0，且并非单图/无共同支持驱动 | 组间区间宽或质量单元格少于 10 图；保持探索性 | 所有预定对比上界均低于 3%，或无可支持的条件性机制 |
| RQ3 | 预定温和剂量的平均绝对漂移达到 5%，并有自然质量方向支持 | 仅极端失真有效、肉眼不可辨、真实与合成方向冲突 | 温和剂量漂移上界低于 3%，或常规增强已足够 |
| RQ4 | 标签相对稳定可匹配的参考长度覆盖至少 80%，测量失败率达到 10%，不同合理规则方向一致 | 覆盖或节点规则不稳；误桥指标未完成 | 无法建立可靠参考管段身份；禁止用额外训练弥补 |
| RQ5 | 宽度误差明确超过合成标定/定义敏感性范围，且不是删掉细支造成 | 匹配覆盖显著变化或宽度定义改变结论 | 宽度误差小于数字化可辨认范围，或临床物理尺度要求无法满足 |
| RQ6 | 仅批准进一步参考核查：同图不同标签使模型比较方向发生可复现翻转 | 标注来源不明、样本结构过窄 | 无专家参考却要求普遍噪声/真实血管结论 |
| RQ7 | 在固定 20% 转人工预算下，留出风险至少相对下降 10%，且优于原生质量规则 | 严重错误病例过少、仅校准集有效 | 留出无增益或收益来自不可接受的疾病组拒绝差距 |
| RQ8 | 核心局部参考到位，病灶邻域误差在匹配设计中富集 | 数据、许可、可见性未解决 | 核心病灶参考无法在周期内获得 |

## 25. AI Intervention：问题成立之后怎样设计实验

### 25.1 第一层：不训练的工作点控制

预先固定全局阈值候选集，例如 $t\in\{0.30,0.35,\ldots,0.70\}$。不按疾病、图像或测试表现临时添加阈值。

比较三种规则：固定 0.5；开发集 Dice 导向选择；满足保护条件的测量误差导向选择。阈值选择必须在校准部分完成，再在留出部分评价。可用预先登记的分层两折交叉拟合形成开发估计，最终以完整开发集按同一规则确定一个阈值用于未参与选型的 test。

118 图已经被用于多轮开发，新的交叉拟合只能减少**本次阈值选择**的偏差，不能把这批图重新包装成完全未用过的验证证据。真正的最终效果仍要看冻结后的测试；不在 test 上选择哪种规则。

如果只是工作点改变就解决主要误差，不需要再证明一个复杂 loss。若进一步使用单调概率校准，它通常改变概率刻度或阈值解释，不等于改善排序；AP 与结构误检有助于识别这一点。

### 25.2 第二层：由误差机制选择一个训练改动

| Stage A 主要发现 | 首先考虑的改动 | 它改变的测量错误 | 必须排除的替代解释 |
|---|---|---|---|
| 可见细支长度低估，伪骨架负担低 | 普通骨架监督对照，或受限的细支采样 | 增加标签支持的网络延伸覆盖 | 是否只是增粗；曝光是否增加 |
| 长度低估和伪骨架并存，数量误差方向不稳定 | 一个有像素/空间约束的测量匹配辅助项 | 同时限制欠量和过量，减少单向 Recall 偏置 | 伪枝配平数量，或软骨架与硬测量不一致 |
| 主要是整体边界膨胀 | 工作点或单一边界/直径平衡控制 | 降低面积/宽度偏差 | 是否牺牲细支覆盖造成表面改善 |
| 主要集中在质量条件 | 剂量匹配的增强或受限质量采样 | 减少质量引发的表型漂移 | 合成失真不代表真实；输出恒定化 |
| 局部排序冲突解释大部分路径测量失败 | 仅此时考虑 PAIR vs SHUFFLE/POOL | 改变特定前景—背景冲突 | 一般困难排序而非配对机制；额外误桥 |

不同时实施表中全部改动。优先选一个机制最清楚、改动最小的候选，普通已有方法作为控制而不是创新包装。

### 25.3 一个可实现的测量匹配备选，而非默认方案

仅当骨架欠量/过量的确是主要问题时，可考虑在像素损失上加入局部软骨架数量匹配。定义软骨架近似为 $\widetilde S$，将裁块内有效区域分成预先固定的格子 $\Omega_j$：

$$
\mathcal L=\mathcal L_{\mathrm{pixel}}+\lambda\mathcal L_{\mathrm{quantity}},
\qquad
\mathcal L_{\mathrm{quantity}}=
\frac{1}{J}\sum_j
\frac{\left|\sum_{x\in\Omega_j}\widetilde S(p)(x)-\sum_{x\in\Omega_j}\widetilde S(Y)(x)\right|}
{\max\left(c,\sum_{x\in\Omega_j}\widetilde S(Y)(x)\right)}.
$$

这里的常数 $c$ 是根据训练图确定的稳定化尺度，不能用测试误差调。该式仅是**待验证技术草案**：软骨架作用于预测和标签双方以减少算子失配，主要评价仍使用固定硬 Zhang 骨架；训练软代理与主要硬指标的相关性必须单独验证。

局部格子只是避免整图“这边漏了、那边乱画”完全抵消，并不保证正确位置。裁块截断可能造成人工端点，因此在 GT/预测双方采用同样的有效内部区域；格子大小和边界留白从训练图/合成测试冻结。空前景格子必须惩罚伪骨架，不能因为分母为零跳过。

保留原像素监督、增加预测端伪骨架检查，与普通 M1 和已知结构方法作适当对照。若软骨架导致显存/时间明显增加，或梯度使伪枝增多，即使主要数字短期变好也应停止。

**新颖性边界：** 这不是“首次测量感知损失”的声明。软骨架、中心线约束、直径平衡和类似统计约束均有前人工作；正式采用前应就最终公式继续作近邻核查。当前更稳妥的贡献是问题与验证闭环。[L14–L16]

### 25.4 正式对照与实验冻结

默认正式矩阵为 M0、M1、一个候选，各三个新匹配种子；同初始化种子、裁块流、优化器预算、有效 batch、验证点、模型选择规则、推理和阈值规则。候选若改变采样，另行建立**曝光匹配的采样控制**，不能继续声称裁块序列相同；必要时增加对照，预算重新批准。

固定训练步数前检查开发学习曲线，不能因历史 10k 已运行就宣称收敛充分。预算允许时，优先对所有方法等量延长关键比较，而不是只延长落后的候选。每条轨迹报告成功更新、AMP 跳步、耗时、设备、显存峰值、版本和失败状态。

若候选本质上就是普通 clDice/已知宽度平衡方法，不把它命名成新方法；正式矩阵可以直接写已知方法对照。若引入自定义公式、且最近的已知结构方法未被包含，需要增加普通结构基准或明确降级为课程可行性研究，不能用弱对照宣称算法优越。

### 25.5 主要终点、保护门与统计方案

对每个种子，按图像计算候选与 M0 的配对主要误差差：

$$
\Delta_i=E_{\mathrm{S},i}^{\mathrm{candidate}}-E_{\mathrm{S},i}^{\mathrm{M0}}.
$$

主要报告宏平均差、95% 图像级配对 bootstrap 区间、相对下降幅度和各种子一致性。建议把**至少 10% 的主要误差相对下降**作为有价值的技术改善目标，同时报告绝对下降；只报 p 值不足以说明值得使用。

三个种子逐个呈现，不把同一图像的三次预测当三例独立受试者。可补充先按图平均种子后对图像重采样的条件性区间，但这不足以估计所有未来训练的随机性。主要比较只冻结一个；候选对 M1、多个形态和三个疾病对比作为预定次要分析，使用 Holm 校正或明确探索性标记。

### 25.6 MAE、相关、ICC 和 Bland–Altman 怎么使用

| 工具 | 回答的问题 | 必须注意 |
|---|---|---|
| MAE | 平均偏离多少原始单位 | 单位必须是密度计数比、像素长度或数字宽度 |
| MARE | 相对于每图参考值，偏离多少 | 零/近零分母不稳定；空标签分开报告 |
| Signed bias | 系统性高估还是低估 | 正负抵消不能代表逐图误差小 |
| Pearson/Spearman | 排序或关联是否保持 | 高相关不代表数值相同 |
| ICC(A,1) | 两个固定测量流程在图像间是否绝对一致 | 使用绝对一致、单次测量；不要误报 consistency ICC；组间变异小可能使 ICC 低 |
| Bland–Altman | 偏差、个体差异范围、误差是否随量值改变 | 一致性界限和界限的置信区间不是同一东西；不自动代表临床可接受 |

ICC 在此定义为两向、固定测量方法、绝对一致、单次测量的形式，报告所用公式/实现与区间，不只写“ICC=0.9”。若软件只有另一种命名或缺少该形式，应实现后用已知公式/独立软件核对，而不是把不同 ICC 混用。[L19，全文访问受限；实现选择为本文预定方案]

对近似同方差、差值分布适当的数据，Bland–Altman 可展示：

$$
\bar e\pm1.96s_e.
$$

若差异随量级扩大，应考虑预定的对数比值/比例差或稳健区间，不能只画两条宽界限就宣布可替代。当前没有临床一致性界限，所给界限只能描述标签相对误差。[L17]

## 26. 性能损失与医学相关收益：多目标评价框架

### 26.1 Dice 降低 0.2–0.5 个百分点，是否可以更好？

**可能，但必须说清“对哪个用途更好”。** 对已指定的骨架表型测量用途，若主要测量误差稳定下降、独立测试成立、错误结构没有增加到不可接受水平，像素 Dice 小幅下降不必否决方案。反过来，测量数字变得更接近但出现大量伪血管，不是更可靠的医学测量模型。

目前不能从文献为 FIVES 推出一个普遍的“临床允许 Dice 下降 0.5 个百分点”。本报告建议把它作为技术非劣界限的候选值，并要求**在 Stage B 看结果前冻结**。

### 26.2 建议的预先保护规则

| 层次 | 指标 | 候选初值：相对匹配 M0 | 性质 |
|---|---|---|---|
| Primary | `MARE_S` | 相对下降至少 10%，绝对下降报告；配对区间支持改善 | 技术获益目标，非临床 MCID |
| 关键测量次要 | 面积密度 MAE | 不出现明确恶化；若变差必须解释取舍且不得超出预定上限 | 防止骨架数量改善却面积严重失真 |
| Pixel guard | Dice | 下降不超过 0.005，即 0.5 个百分点 | 候选最大允许损失 |
| Purity guard | Precision | 总体下降不超过 0.005 | 防止召回无约束扩张 |
| Ranking guard | AP | 下降不超过 0.002，即 0.2 个百分点 | 防止排序明显恶化被单阈值掩盖 |
| FP guard | 每图 FP/FOV 的宏平均 | 增量不超过 0.001，即 FOV 的 0.1 个百分点 | 使用稳定的固定分母 |
| Subgroup guard | 各疾病组误差及 Precision | 任何组出现主要误差增加超过 10%或 Precision 下降超过 1 个百分点，触发审查/HOLD | 小组区间宽时不能宣称非劣 |
| Structural guard | 预测额外骨架、误桥/伪支 | 不能有明确的伪结构系统性增加；RQ4 路线须完成量化误桥指标 | 目前缺失时不得宣称拓扑安全 |

面积密度 MAE 的候选上限建议使用训练参考密度均值的 0.5% 作为绝对误差增量尺度，**不是允许面积密度相对变化 0.5 个百分点的混写**。若该尺度低于标签数字化波动，应在 Stage A 后、Stage B 前明确替换并记录理由；不能在测试后改。

对具有硬界限的指标，不仅比较点估计；应报告配对差区间与非劣界限的位置。样本不足导致区间跨过界限，应称证据不足，不能只凭均值好看宣称通过。多个守门指标同时满足才称“受约束改善”；不把它们加权平均后互相抵消。

### 26.3 哪些东西不能拿来交换

不可交换的是：数据独立性和测试保护、正确统计单位、可靠参考、患者安全主张的边界，以及禁止通过病灶删除、错误桥接或过量伪血管制造量值补偿。

不是所有传统指标都必须绝对不下降；但**越过已冻结的最大损失、出现严重局部失败、或不能解释的某组恶化，不能用总体主要终点改善盖过去**。图像级信号不能替代临床安全研究。

## 29. 风险与当前不可验证主张

**参考不等于解剖真值。** FIVES 的标注规则不要求为了连续性补画；看起来连通的预测可能偏离参考且无法验证。[L01]

**可见细血管不等于毛细血管。** 当前“细”是训练标签 EDT 半径不超过 4.0 原始像素的工程分层，不是依据成像标定和生理管径的分类。[R13]

**同尺寸不等于同物理尺度。** 2048×2048 和统一相机条件有助于数字测量对比，却不能补上每眼放大率/物理尺度或 A/V 身份。宽度只能称 pixel-space proxy。

**未知患者相关性。** 图像级去重不是患者级划分；bootstrap 区间不应被写成新患者临床泛化。

**质量与疾病不独立。** 只要某些质量状态集中在特定组，原始组间误差差异就不能简单归因疾病。即使回归调整，缺失临床因素仍然存在。

**训练目标与主要指标不完全一致。** 软骨架近似、硬骨架计数、几何长度和真实管腔网络是四个不同对象。以其中一个改善推断其他全部改善，需要额外证据。

**全局数量可能被错误位置补偿。** 因此主线不能只优化总长度数值，必须同时看漏检、额外骨架、误检和局部案例。

**多指标和多次开发会制造选择性结果。** 冻结主终点、有限候选、一轮有依据的修改；保留所有尝试，不在多个病种或阈值间事后挑最有利者。

**资源预算仍有不确定性。** 5080 的约一小时锚点只属于当前 10k 轨迹，4070 的加速是短程验证，新损失、更多验证或更长训练会改变成本。性能测试不能代替研究效果实验。[R01、R04]

**本次未新算形态结果。** 仓库记录足以确认现有训练和部分机制现象，但此次没有获取并运行全部 GT/预测数组。因此本文不填写不存在的 `MARE_S`、ICC、Bland–Altman 或疾病测量偏差数值；这些就是 Stage A 要回答的未知量。

## 30. 推荐下一步：只批准第一笔投入

今天最值得做的是批准 `morphology_discovery_v1`，冻结一页 Stage A 协议，然后恢复 118 图对应的 M0/M1 预测、标签和 FOV，输出面积/骨架密度的逐图误差与疾病×质量分层。

最迟在累计 3–5 人工工作日的第一笔预算末，形成 GO/HOLD/STOP 文件。若仅资产恢复就超出预算，应单列恢复成本，不能把它写成“研究方向本身太难”。若指标已经可靠而没有足够失败信号，允许及时完成负结果报告，把节约的训练预算用于复现和课程解释。

## 33. 如果今天必须选：明确排序的 Top 3

### Top 1：可见血管骨架密度测量可靠性——最推荐

**临床价值：** 解决自动定量作为测量工具是否可信的问题，直接面向血管表型研究，而不是把像素提升包装成医学进步。当前证明层级是标签相对分析有效性。

**科学价值：** 先检验“高 Dice 是否足够”，再区分漏检、伪结构和边界增粗；允许“无需新方法”“只需改选择规则”“确需新监督”三个可解释结果。

**为什么适合 FIVES：** 二值标签、疾病/质量字段、当前固定 FOV、M0/M1 对照和已有整图骨架均可复用；不需要额外病灶标注、临床结局或 A/V 标签。

**最小验证：** 全 118 图的骨架密度 `MARE_S`、面积密度误差、漏检/额外骨架及疾病×质量偏差。**难度：** Stage A 2/5，完整研究 3/5。**方向性时间：** 3–5 人工日、0–0.5 GPU-hours、0 新训练。**课程预算：** 16–24 人工日、16–24 GPU-hours、条件性新增 10 次完整轨迹。**Codex：** 5/5。

**最大风险：** 当前分割已足够用于这一代理测量，或“数量变准”来自错误结构抵消。前者是有价值的负结果，后者必须被保护指标否决。

### Top 2：疾病组间的 AI measurement bias——最便宜、最适合马上做

**临床价值：** 直接防止把自动测量偏差误当成疾病血管差异。它把课程要求的疾病亚组从排行榜变成科研问题。

**科学价值：** 使用 `AI−GT` 误差和组间对比偏移，回答偏差的方向与幅度，而不只比较 Dice。质量混杂和未知患者因素使它不能单独承担强疾病因果解释。

**为什么适合 FIVES：** 四病种、原生质量字段和成对 GT/预测已具备，主要是评价和统计增补；无需疾病分类器。

**最小验证：** 面积与骨架测量误差逐图表、三项疾病对正常对比、疾病×质量交叉表。**难度：** 初查实现 1/5，完整研究总体 3/5。**方向性时间：** 3–4 人工日、0–0.5 GPU-hours、0 新训练。**独立主线预算：** 12–18 人工日、12–20 GPU-hours、条件性 7 次完整轨迹；并入 Top 1 时不重复累加。**Codex：** 5/5。

**最大风险：** 质量和疾病缺少共同支持，或者误差来自标签/人群结构。出现这种情况应保留描述性偏差，不训练一个声称“消除疾病偏倚”的模型。

### Top 3：图像质量引发的表型漂移——备选主线

**临床价值：** 针对成像条件改变造成的假性测量变化，适合定量分析的稳健性需求；真实随访价值仍需重测数据确认。

**科学价值：** 同一图像做预定、温和的成对扰动，结构参考不变，比仅观察低质量图 Dice 更容易定位变化来源；自然质量分组作为外部于合成扰动的现实检查。

**为什么适合 FIVES：** 已有 IC/Blur/LC，且可以复用现有模型，不增加人工标注。FIVES 没有真实同眼重测，必须称“配对扰动鲁棒性”，不称临床 test–retest 验证。

**最小验证：** 温和模糊、对比度、亮度/颜色的预定剂量测试，同时检查测量漂移和相对 GT 的绝对误差。**难度：** 3/5。**方向性时间：** 4–6 人工日、0.5–2 GPU-hours、0 新训练。**课程预算：** 18–28 人工日、18–30 GPU-hours、条件性 10 次完整轨迹。**Codex：** 4/5。

**最大风险：** 合成扰动不代表真实采集问题；一致性变好可能只是输出变得僵化。因此它排在前两者之后，而不是同等推荐。

**最后的项目决定：先做 Top 1 + Top 2 的共同零训练审计；只有问题和可改善空间成立，才批准算法干预。C1 暂停不是损失，避免在错误主问题上继续投入才是本轮调研最重要的收益。**
