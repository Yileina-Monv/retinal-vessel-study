# NL终点结果与评价覆盖复核

## 供组长审查的结论

原T0/TW三种子正式实验未证明区域加权具有可靠、受保护的邻域细血管收益。NL两种子固定终点已完成，也未达到其预设成功标准。标准nnU-Net继续作为工作基线N0。

补充评价显示，nnU-Net完整流程改善整体Dice，也提高了更广范围的邻域候选路径覆盖；同时逐图平均邻域误报密度上升，存在局部质量代价。不能把不同分母的收益与代价相减，或宣布原TW成功。

## NL完成后发现了什么

100 epochs、两个seed、固定最终checkpoint。原主指标NL−N0平均+3.7393pp，CI[-4.1667,16.2393]；2027 +8.3333pp，2028 −0.8547pp。Dice平均+0.0193pp，CI[-0.0443,0.0883]，不能称可靠改善或正式非劣效。2027远处Recall、2028 Precision与FP/FOV方向保护未通过。

每个seed合计命中均59→58/77；2027宏均值收益主要由一张单目标图片0→1驱动。同图跨seed平均后去掉该图的影响诊断为−2.0433pp；正式评价不删图。

新邻域路径口径NL−N0为−1.6225pp，CI[-4.5983,0.6108]，没有更广覆盖增量证据，也不能确定方法更差。NL仍按旧目标训练，本次不是按新目标设计的新实验。

## 为什么补充评价

原主指标：原生骨架2×EDT宽度代理≤3、原d1=1像素、9有效图77位置、19NA。它可复算，但覆盖狭窄，不能代表完整细分支。原方案PPT提供研究问题，具体宽度代理和阈值是技术实现与冻结协议，不能混称医学直径。

宽度2/3/4/5对应8/9/18/18有效图、28/77/699/1262位置。原S3只触及174条既有候选路径中的18条；被触及路径邻域部分的选择覆盖中位数6.27%。候选路径定义更宽且未医学审核，不能称其余路径程序漏算。

补充口径沿用既有候选路径：相对FOV参考宽度≤6、参考长度≥20，与原near和Omega相交；逐路径计算d1，再图内平均、跨图平均。18图174路径、5136唯一位置（5168路径出现次数），仍有4条1–2位置路径及2张单路径图。GT图路径不等于医学分支，d1仍是原生1像素，不完全尺度一致。

该规则在本轮重算前记录，但Dev早已反复使用，属于事后探索诊断，不是前瞻注册、不替换原主指标、不重判旧成功条件。其他Loss与模块没有在本次统一重评，不能称全部历史模型均已重评。

该图跨seed平均密度0.3505%→6.9704%。全18图宏均值差+0.4302pp；只作影响诊断去掉该图，其余17图+0.0661pp。公开计数保留该图。弧边符合扩张/偏移表现，另有GT未标注的突出结构；医学真实性未知。

按现有逐图计数，两seed合计FP像素23815→22173，而逐图等权密度均值上升，源于不同邻域面积及错误分布。累计像素不能当独立样本；宏均值与面积汇总回答不同问题，两者完整报告而不择优改口径。
