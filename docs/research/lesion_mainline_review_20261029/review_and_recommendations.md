# 后续审阅与建议

日期：2026-10-29。本文归档完整决策稿之后的讨论；属于方法审阅，未采纳为正式执行协议。

## 保留的研究逻辑

| 阶段 | 证据与认识 | 下一问题 |
|---|---|---|
| T0/TW | 已测试的区域统一加权未形成稳定、受保护的局部增量 | 监督对象与方式是否足够针对细血管？ |
| B1/B2 | 全 FOV 细路径召回提高，伴随 Dice、误报和结构指标代价；局部附加结果也不足以宣布可靠改善 | 能否获得更好的整体分割基础？ |
| nnU-Net | 完整流程带来整体、细路径与结构收益；出血邻域有受益信号，严格保护仍未通过 | 固定强基线后，能否获得原目标上的额外局部增量？ |
| N0/NL/NR 提案 | 尚无新结果 | 局部判别监督是否有效，选择真实出血位置是否有额外作用？ |

此表按问题组织，不把并行探索虚构为严格顺序。TW 的负结果保留，不能借 B1/B2 改写为“TW 提高召回但降低 Dice”。nnU-Net 不代表已定位架构瓶颈，也没有消除全部误报风险。

## 三项执行前审阅意见

### 1. 先确认排序假说与残余遗漏相符

TW 失败及 B1/B2 的代价，不足以推出 nnU-Net 当前遗漏必然来自目标—背景排序不足。血管概率 0.4、背景 0.05 时，目标虽未跨过 0.5，二者仍可能已有较大 logit 间隔；排序改善也可能主要来自背景降低。

D0 应明确统计：真正 d1 漏检、参考可信且符合拟用背景范围的目标中，有多少存在间隔不足，分布在哪些图；并同时记录目标和背景分数。中心低分但 d1 已命中的点不应混入主遗漏诊断。诊断信号不能代替 L1 的主终点。

### 2. 把局部收益、保护与位置作用分层解释

NL−N0 回答局部监督对原目标的增量；NL−NR 回答真实出血位置选择的额外价值。局部改善成立、位置额外作用尚未证实，仍然是可报告的研究结果。

原稿同时提出新增 Dice/局部 FP 区间保护，以及逐 seed 分别通过多项区间条件。在有抽样波动时，要求置信区间完全处于有利一侧，是很强的联合要求，不能口语化为“只是没有明显变差”。局部干预若对远处接近零效应，也可能无法满足该严格门槛。

建议在最终执行卡中明确：原有冻结保护原样保留；新实验主判断的统计层级；新增逐 seed 全部通过是否作为更严格的复现层级。此处没有确定替代门槛，没有放宽零恶化线，也没有授权运行后修改判定。原稿第 6.2 节的规则原文仍保留。

报告应分别列示：主收益是否支持、保护是通过/明确恶化/证据不足、病灶位置作用是否支持。即使严格联合成功不成立，也不能把“不能排除恶化”写成“已证明恶化”，或把局部增量抹去。

### 3. 用有限工程核对确认监督实际发生

共同 crop 可见、一对一匹配、背景支持与多项卡尺可能导致大量目标被共同跳过。应先报告有效辅助批比例、目标曝光、图/链贡献集中程度和 NL/NR 剂量一致性，确认该干预具有足够支持。

距离、卡尺、覆盖阈值、margin 和梯度剂量都属于提案参数，未获得本地可行性验证。后续建议允许在不查看新增 Dev 效果的工程阶段修复明确问题、记录差异并形成新冻结版本；原稿的重试上限与不可修改条款尚未因此被正式替换。科学运行开始后不能通过改设置挽救阴性结果。

## 下一步与预算

1. 一次有界 D0，交付现有残余遗漏、局部误报、参考可信度和配对可行性；缺资产则记录无法判断的范围。
2. 假说和工程条件成立后，再冻结 N0/NL/NR、seed2027/2028 的 L1；三臂各从共同初始状态独立训练。
3. 首轮按预定层级解释结果。seed2029 仅保留为原稿中的条件复核提案，不自动追加。

首轮六条轨迹：150000 次训练尝试、30000 次 Train-only 监控、168 张 Dev 终点预测图次。按历史速度线性参考约 73.9 训练进程小时，不是已核实 GPU 小时；3090 的显存、并发和耗时须实际验收。

早期跨实验审计提出的训练 patch 消融属于解释完整流程约 2 pp 收益的机制问题。用户明确要求回归病灶邻域主线之后，该方案已暂缓；原文仍归档，不能与 L1 并列为当前第一优先级。

## 可用于阶段汇报的说明

我们关注确定出血邻域内参考细血管的遗漏。正式 T0/TW 对照未支持区域统一加权的可靠增量；随后结构监督实验显示细路径召回具有可改善空间，但同时出现误报与整体质量代价。nnU-Net 的完整流程比较提供了更强的工作基线，也带来局部受益信号，但尚不能宣布可靠的病灶邻域改善。下一阶段固定该流程，以原邻域细骨架 d1 为主终点，比较真实出血邻域与匹配非出血位置的同剂量局部判别监督，同时考察局部误报、整体质量及远处表现。正结果将说明受保护局部增量及位置作用；阴性或不确定结果将界定该干预的适用边界。研究目标始终保持为减少目标区域的细血管遗漏及其代价分析。
