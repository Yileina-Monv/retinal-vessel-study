## 结论先看

D0发现部分既有病灶邻域漏检点与近背景的分数间隔不足，因此支持检查Train上能否构造公平对照。该检查已经完成：**V1和V2均未达到预先固定的80%图片覆盖门槛，停止进入增强重放和GPU验证。** 这不是“辅助监督训练后无效”，因为尚未开展该训练。

351是GT细骨架点数，不是血管条数、图片数或患者数。V2的87.46%点覆盖不能替代76.67%图片覆盖，也不是增强后的训练曝光率。

## 原研究问题与D0证据

原主线仍是出血邻域细血管可靠检出，保留T0/TW三种子正式负面结论。标准nnU-Net为后续流程基线，不把其整体Dice收益归因于单一模块。D0复用标准nnU-Net seed2027/2028、100epochs固定终点、Dev28、阈值0.5、原FOV/GT/d1；主指标有效9图77位置，其他19图NA，不删除稀疏或不利病例。

两种子各命中59/77、遗漏18点，共同遗漏17点。相对目标中心logit减全部合法近背景logit均值的间隔<1且原d1漏检：2027有7/18点、2028有11/18点，各分布在5图，满足预定至少3图的诊断条件。它只支持下一步可行性检查，不证明该间隔是漏检的原因或排序Loss有效。

这些合格点的d1最高概率分别至多1.797%和1.818%，远低于固定50%阈值；相对排序变好可能只压背景而没有找回血管。另11/18和7/18遗漏点的间隔已经至少1。不能用单一机制解释全部漏检。

邻域FP像素分别11829和10344；18张非空邻域图的宏平均FP/面积为1.999%和1.842%，FP/背景为2.466%和2.313%。大部分绝对FP位于面积更大的远处，不等于病灶邻域是主要误报来源。内部/邻域/远处/U残差均与全FOV对账；区域宏平均与全图像素合并比例不能混用。

## 两版Train匹配设计与失败

只使用冻结Train110 GT、原生Zhang骨架及原宽度≤3定义，NL为原Rnear目标，NR为同图Rfar候选。原FOV、出血邻域与不确定区域处理保持一致。同图宽度差≤0.25原生像素、FOV径向位置差≤0.05、半径12局部Omega血管密度差≤0.05；最大基数一对一配对，固定独立RNG打破平局，不用模型分数或Dev漏检坐标生成训练目标。

V1还要求合法背景候选池大小相差≤10%，240个未配对点中170个被该条件排除、33个无几何候选、37个因一对一竞争未配上。V2经用户批准把池大小改为描述项，改控两侧实际各2个不同合法负例及联合距离分层计数；其他几何条件和覆盖门槛不变。合法负例仍在对应区域/Omega内、距完整GT2–8且距目标≤12原生像素。

V2剩余44点：33无几何候选、9一对一竞争、2无匹配双负例。7张完全无配对图片共13个目标，其中6张没有几何合法边，另1张有几何边但无合格负例配对边。独立重建全部合法图并核验最大匹配；不是多换几个随机种子就能提高该规则下最大配对数。

负例联合格子匹配不代表连续距离完全一致；GT距离分层为[2,3)…[7,8]，目标距离为[0,2)…[10,12]（末格含右端），实测差最大分别1、2原生像素。V2未执行的replay子项继承了V1“至少1/最多2个”负例文本，与V2固定2个规则不一致：如未来重提案须先消除歧义，不能宣称增强后同剂量已验证。静态307对均为两侧各2个，不影响本次静态失败判定。
