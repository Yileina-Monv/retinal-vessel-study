D5可与概率材料审核并行。下面是未来材料检查设计，本 PR 只复核公开数表，未执行这些图像/概率诊断。

`q(s)=max p(x), x∈Ω且||x−s||₂≤1` 只在正式匹配支撑是预测前景时与主指标对应；若支撑为预测骨架，先按正式实现重现，q只作诊断。欧氏d1不是整个3×3，空预测距离为无穷，主指标零分母保持NA；支撑可跨Rnear边界但须在Ω内。

D2背景也用同形状、同有效支撑的d1邻域最大值，不将目标最大值与一个随机负像素比较。建议固定距V 2–8像素、距目标≤32、位于Rnear∩Ω，整个窗口合法；按固定hash每点至多均匀抽32中心，无合法候选为NA，不改抽远处容易背景。比较同一背景集合上目标分位、q−背景95%分位和分开目标/背景变化。曲线同时含主/near像素Recall、全图FP/FOV、near FP/固定Rnear面积、far Recall及无参考结构。全局阈值可作为零训练方案，但同Dev选阈值是描述性；逐图oracle不构成推理方案。单调校准保留排序，无偏置温度缩放还不改变0.5边界。

如仍不能区分机制，未来可在已有checkpoint固定Train probes上分别反传目标BCE、其他正例、A负例、A外项及Dice；不执行优化器更新，AMP先unscale、clip前测loss/logit梯度/选定层范数与余弦。它是新probe，不是历史训练梯度；分项loss或像素比不能替代参数梯度。

### 共同控制和预算提案

取得真实代码后，再冻结同Train110/Dev28、M0 hash、优化器/AMP、正式学习率序列、batch4/512原尺度crop、归一化、图频次、增强、成功更新与配对RNG。原draw不可恢复就建立共享计划并同期重跑C0，旧T0仅作历史锚点。额外缓存、反传、失败步和wall time单列。

机制阶段建议seed2026/2027、每臂440成功更新=1760 draw；只有110图×4槽计划确实完整时才称4轮。相同固定Train probes比较干预@440与同期C0@440，两个seed分别判断；不靠相对M0变化，不用短程Dev挑效果。候选/剂量确定后，各臂从共同M0重新开始，3seed×2000固定终点；不挑Dev最好step。

2000是公平预算，不是收敛声明。4000必须在查看新Dev指标、概率、结构之前，依据预注册Train规则共同决定所有臂/seed；总loss仍降不足以触发。若无可执行Train触发规则，就不条件性续训。4000不覆盖2000主结论；要承担采纳须预设多终点决策或新冻结验证。

### 共同采纳门槛提案

固定0.5相对同期T0：主差≥+3pp，三seed均正，按图配对95%CI下界>0；至少3图净改善、所有leave-one-image-out均正、总位置净hit正，结构复核支持真实细血管。+3pp是资源投入的工程门槛，不是临床差异或功效保证。

容许恶化量建议仍为0：Precision/far差CI下界≥0；全图FP/FOV、near FP/|Rnear|、near无参考支持骨架长度密度差CI上界≤0；预定完整范围无确认新增错误连接，疑点未解决不通过。另报背景条件FP/|Rnear\V|，不能混淆分母；无参考骨架不能仅除以预测骨架以免新增结构稀释风险。正确管径恢复与宽度过冲分开。

同FP辅助提案：共同预算B*取正式Z0@0.5宏FP/FOV原始精度（约1.16341%），所有seed/方法相同；T0/候选都在0–1、步长.001取最低可行全局阈值。各seed主差>0、near FP点估计不增、far点估计不降且结构通过；实际全局FP≤B*，不另要求+3pp。固定0.5主收益、全部保护、此辅助检查三者均过才进入最终冻结。它在同Dev上选阈值，仍是描述性，不能把约束出的FP区间当独立保护保证；若推断须重抽样中重选阈值或预冻结交叉选择并说明估计目标。不偷偷换T0预算锚点。

主CI建议先跨seed平均逐图差再整图配对bootstrap，冻结图顺序、NA、RNG重置和分位数；10000次只减少蒙特卡洛误差，不增加9图证据量。区间不确定≠无伤害，也≠证实机制无效。所有Dev仍是开发证据；方法、阈值、预算、实现和保护均另行采纳冻结后，才可能安排官方Test终局评价。

## 4. E1/S1：固定图像频次，只定向一个裁块槽

**进入条件**：D0/D1及盲审通过，可见可信的Train目标缺少分散曝光，而且D5证明单槽能形成可测操纵。曝光充分或主要是输入/标注问题则撤销优先级。

**唯一改变**：crop的top-left。损失保持T0 BCE+Dice，网络、尺度、图频次、增强不变。实际修改点待正式Dataset确认，历史`retinal_data/fives.py`只作线索。

**算法提案**：Train完整V上生成正式T，先完整骨架分链并保留短链。每图每轮4槽，有T图只替换一个预定轮转槽，如`(epoch+stable_hash(image_id)) mod 4`，无T图全保留。均匀选含T完整链→均匀选该链T点→固定jitter，使目标尽量位于512crop的128–384中部；边界共用有效窗口投影并记录夹紧。其他3槽坐标与所有槽flip/rotation保持原draw。新坐标选择用独立RNG，不消耗原增强RNG。每轮改动比例目标图数/440，最多25%。

**对照**：C0原均匀；S1目标；Cnear同图同槽同jitter/投影、中心改从Rnear均匀取。原则保留Cnear；只有逐draw窗口及变换完全相同才合并并注明不可区分。预算省略须收窄归因，不能人为排除Cnear含T窗口制造差异。

**离线门槛**：完整8000 draw；每图曝光=所有draw出现T点实例数/该图完整T点数。图像中位数≥C0的1.25倍；固定C0最低四分位图逐图不降（并列按image_id）；至少半数目标图增加。C0中位数0时预设S1中位数≥1次/点，同时报告零→非零；不用比值除0。另列链/点覆盖、重复集中与边缘截断。25%是工程操纵门槛，不是曝光充分性定理。

**机制响应提案**：两个seed分别至少半数目标Train图的平均q相对C0@440为正，图像中位局部目标−背景间隔差正；使用相同固定probe。否则最多说明操纵成立，不进入效果采纳。C0+S1机制共1760成功更新，效果共12000；Cnear再加880/6000。均为未批准预算。

**日志**：每draw图/seed/epoch/slot、原/新坐标、链/点、jitter/投影、增强、T/A正负/FOV；每图链点曝光；固定probe p/q、背景、空T批；每图每seed原尺寸概率及hash、指标、find/lost、local FP、厚度、新连接及盲审分歧。受控资产不进Git。

**停止与阴性**：几何不能复现、操纵弱/过度集中/上下文严重丢失即停止。Train纠错而Dev无保护收益说明当前实现/预算未转化，不自动加比例。S1≈Cnear>C0且曝光相近可支持简单邻域采样；S1>Cnear且曝光更多加强目标对准解释，但不证明唯一中介。出现FP交换先D2，不临时叠加难负例。

## 5. E2：低概率真实目标正例纠错（条件备选）

**触发**：对齐、可见、曝光充分；局部排序合理却低于阈值，D2找不到保住全图/near FP与far的单一全局阈值。阈值方案已足够则E2不优先。

只在T0上加真实T正例BCE，采样不变：

`L = L0 + (λ/B) Σ_i [ Σ_(s∈T_i) softplus(−z_i(s)) / max(1,|T_i|) ]`。

空T裁块贡献0，batch分母含空裁块；T须受真实V支持，不将d1容差膨胀区全标正。完整图生成后同步变换。对照T0、T0+正例BCE、T0+同T的`1−mean(p)`，不移植整套M1。低p的logit梯度分别含`−(1−p)`与`−p(1−p)`；这是机制差异，不是效果保证。

剂量提案：共同M0上32固定含T的Train小批，预选最后解码块，`λ=0.1·RMS(||g_base,k||)/(RMS(||g_aux,k||)+ε)`。逐批范数后RMS，不先平均梯度向量；AMP先unscale、clip前测。两个辅助候选各按此规则匹配初始尺度后固定，不用Dev调λ；梯度零/不稳先查实现，不异常放大。0.1只是一层/初始时刻的工程剂量。

记录p分档、loss/logit梯度、范数/余弦、q/背景、空T批、find/lost与全部保护。机制期须有相对同期C0的目标q及局部间隔正响应，两个seed单列；总loss降低不够。Train已纠错但Dev未过不能否定所有中心线监督；仅主差CI上界也低于+3pp时，才能在当前条件推断范围排除该最低收益。若局部反向排序，撤销E2而按诊断考虑E3，不继续加正例权重。

## 6. E3：目标与附近困难背景排序（条件备选）

**触发**：目标可见、对齐、曝光充分且稳定低于局部背景。必须在E3自己的B(s)与中心logit上再核验；D2的32像素/Rnear/d1最大概率不能直接替代，失败不能只来自12–32环带或不同背景域。E2/E3按错误型选择，不叠加S1开跑。

相对T0只加局部排序，不换骨干/采样：

`L=L0+λ·mean_hier softplus(1−z(s)+z(b))`，margin=1 logit；

`B(s)=A∩Ω∩{x:2≤dist(x,V)≤8}∩{x:||x−s||₂≤12}`。

距离在完整原尺寸图预计算，再与当前有效crop相交；正负点同步flip/rotation后取本次输出logit，不引用crop外。每完整GT链当前crop内至多16不同合法T锚点，每点通常一个困难、一个均匀背景；只有一个合法负例时两排序臂同用一对，短链不复制到32。两臂共用合法锚点和逐锚点对数。先每锚点负例平均→合法锚点平均→合法链平均→除完整batch B，空裁块0；无合法负例锚点、空链不进入其层均值。

困难背景取B(s)内冻结已有Train T0概率最高四分位；均匀也来自同B(s)，尽量不重复。缓存可取已有seed2026/2000 T0、所有臂共用hash；如缺缓存，未来已有模型Train推理仍需另行安排，本次不运行。无合法背景就跳过，不抽远处易例；预定抽样盲审困难负例，不能把漏标血管确信当背景。

对照T0、半困难/半均匀排序、同范围/同对数全均匀排序。λ只由**全均匀排序臂**按E2 Train规则确定，两排序臂共用冻结值，避免困难选择与剂量混淆。记录合法/跳过锚点、距离/分数、图链贡献、Δz目标/背景、间隔、q及全部结构保护。共同logit平移在差值中抵消，但间隔可能只由压背景改善；机制期需相对C0@440同时有间隔与目标q响应，两个seed分别报告。

正式仍须共同收益与保护。只Train好、只排序好、错误连接/far损失均不采纳。困难版未显优势不等于等价或否定局部监督；若诊断变为短断裂或处理链损失，撤销本分支，重新注册单因素实验。
