# nnU-Net 模块与深监督消融：固定终点科研审查

截至2026-10-29。原T0/TW三种子负面结论与Plan B为原主线；此处归档后续流程和单种子消融，不改写历史目标。

## 结论

**建议保留标准 nnU-Net N0 的深监督作为后续工作基线。** 两种新增模块均未获得可靠普通Dice增益；仅最终输出监督降低Dice并增加误报。所有数据来自反复使用的Dev28，Test60仍封存。

### 多尺度模块：两条公平配对轨迹，未获增益

seed2027，原N0复用；Local/Multi各增加2304参数，仅第三分支dilation=1/2不同，保留原CE+Dice和深监督。全部25000训练输入/标签/ID/LR逐尝试配对；5000 Train监控ID配对，历史监控像素摘要不可用。

- Multi−N0 Dice：−0.0272pp，95%图像配对区间[−0.1037,+0.0575]pp。
- Multi−Local Dice：+0.0451pp，区间[−0.1028,+0.2206]pp。预定可靠增益与严格保护未通过，不能说所有模块都无效。
- 邻域宏平均N0/Local/Multi=59.8675/64.7108/67.3461%，命中计数59/55/58（同77位置）。Multi对N0只有1图改善、2图下降、6图不变；唯一改善图分母1，Local也命中该点。局部宏均值不能当作稳定医学收益。

### 深监督分配消融：保留原配置

seed2027，网络59177872参数和8输出头不变。原监督权重为[64,32,16,8,4,2,1,0]/127（7非零），候选为[1,0,0,0,0,0,0,0]。两组系数和为1，最终项系数放大1.984375倍：是归一化监督分配消融，不是固定最终项系数或梯度等量对照。

- 仅最终−N0 Dice：−0.1878pp，95%区间[−0.2978,−0.0602]pp；按原冻结标准，支持原深监督在此配置的Dice优势。
- Precision差−0.6171pp，FP/FOV差+0.1157pp，hard-clDice差−0.2354pp。候选受保护Dice增益不成立。
- 原邻域细骨架召回差+6.4815pp，区间[−16.6667,+33.3333]pp。2图改善、1图下降、6图不变；命中59→57，新增4位置、丢失6位置。
- 分母1的图找回1点贡献+11.1111pp；分母6图丢4点贡献−7.4074pp；分母4图多1点贡献+2.7778pp。总命中计数仅作诊断，不替换冻结逐图宏平均。
- 两个标准种子共同遗漏17/77位置（6图），本候选找回其中3点；不代表17条血管，也不证明病灶因果或医学标注正确。

### 与T0及已有流程结果的关系

标准nnU-Net连续2027/2028相对各自T0的Dice差为+1.9779/+2.0626pp，区间分别[+1.5365,+2.4751]/[+1.6181,+2.5866]pp。两个种子的严格保护均未全部通过。2027的Precision/FP均值不利，2028均值有利但FP区间仍跨零；不能笼统断言已证实两者均有误报增加。

T0是FIVES M0预训练U-Net、2000成功更新、batch4/512裁块；nnU-Net是原生随机初始化、100epochs/25000尝试、batch2/1024×1536、不同网络/预处理/优化器与训练FOV监督。这是流程比较，不能将约2pp收益归因于某单一结构。2026历史接续轨迹不并作同执行协议的第三种子，也不能把同Dev的两个种子当56张独立图片。

## 固定评价与实际成本

100epochs终点、阈值0.5，不选best、不调阈值，无TTA/集成/后处理。全图指标n=28；原邻域细骨架n=9、77位置、19张NA；近邻像素n=18。31项指标保持原有效图集合。原1000次整图bootstrap、PCG64(20261016)索引随包提供；区间条件于该seed及重复Dev，不代表跨seed或独立Test验证。

- Local 24993成功+7安全AMP跳步，Multi 24995+5，最终输出24993+7；各25000尝试、5000 Train监控，不补跳步。AMP跳步位置并非相同，不宣称成功更新掩码完全配对。
- 原工程：模块每组32更新+4诊断；深监督累计32更新+5诊断（含1次失败）。模块Multi终点评价曾因多输出接口错误失败1前向，修复后各67有效前向，没有重训；失败成本保留。深监督终点评价67前向/28图，无失败重试。
- 仅最终监督科学训练15.4055小时，峰值预留8996MiB。墙钟受保存、核验和负载影响，不作算法速度归因。
- A7独立审查核对训练配对、权重/概率摘要、原生shape/范围、像素TP/FP/FN、邻域d1、hard-clDice及全部31指标均值/区间。模块先前独立复盘保留；本次发布只复算公开数表，不冒称重新读取全部概率或训练。
