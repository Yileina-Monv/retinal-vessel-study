# 数据与本地资产

公开仓库提供数据索引、划分、审计记录及下载代码，不提供完整原始数据或模型。

1. 先读 [FIVES 数据报告](../FIVES核心数据集下载与验证_2026-09-04.md)，理解当前来源、重复图和空标签边界。
2. 从 [FIVES 官方数据 DOI](https://doi.org/10.6084/m9.figshare.19688169.v1) 获取数据；已有下载流程见 `data_checks/fives_download_2026-09-04/`。本地镜像版本与官方包不能未经验证就视为完全一致。
3. 使用当前 manifest 指定的相对目录与哈希核对资产。不要更改划分或忽略不一致。
4. 仅分析仓库内 CSV 不需要权重。模型推理或重算形态指标需匹配检查点、原始标签、FOV 和概率/推理实现。

本机历史完整资产仍在原私有归档中，组员获取需要另行获得访问权限。不要将包含旧环境、机器登记和数据的完整私有附件直接公开或恢复覆盖本仓库。

现有训练入口使用冻结身份与机器绑定；首次配置新机器需完成校验并使用新任务身份。未提供通用“一键开始正式训练”，因为正式方案仍未冻结。
