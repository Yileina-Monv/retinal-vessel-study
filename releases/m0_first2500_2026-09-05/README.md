# M0 前 2,500 步开发试跑结果

2026-09-05。已完成本次授权的 2,500 步并暂停，总预算仍为 10,000 步。M1 尚未运行；这是一份单种子、早期开发验证结果，不能作为最终测试成绩或方法提升证据。

## 执行与验证

- RTX 5080；种子 2026；M0 系数 0；512×512；microbatch 4、accumulation 1；4 线程、8 批有界预取。
- 按完整 10,000 步的余弦学习率计划运行前 2,500 步，没有把学习率提前衰减到终点。
- 训练 661.28 秒（11.02 分钟），包含本次进程初始化与保存；验证 179.50 秒（2.99 分钟）。二者合计约 0.234 个 5080 占机小时。加上 60 秒降温记录，本次监督进程共 15.01 分钟。
- 118 张内部开发验证图像，固定概率阈值 0.5；没有搜索阈值，没有读取官方 test 或外部图像。
- 模型权重均为有限值，优化器步数均为 2,500；已消费的 10,000 个裁块与预定样本顺序一致。检查点已打包并由单一登记表接受，状态保持 paused。

## RAM、显存与温度

GB 按十进制记录。训练程序峰值常驻 RAM 3.27 GB、私有提交量 8.72 GB；PyTorch 保留显存 3.54 GB，实际分配 3.32 GB。1 秒资源监测的整卡显存峰值约 6.24 GB，包含其他应用；验证阶段更低。均未达到用户的 12 GB 限制。

- NVIDIA 接口每 10 秒记录一次，共 91 条：GPU 核心采样范围 43–52°C，末次 44°C；硬件和软件热降频标志均未采样到激活。采样峰值不等于连续传感器真实最高值。
- NVIDIA 接口的显存温度返回 N/A。找到已运行的 GPU-Z，其只读 GPUZShMem 接口可用，结构版本 1，设备标识明确为 RTX 5080。通过两次稳定复制和更新时间检查读取，无需修改 GPU-Z 设置或安装插件。
- GPU-Z 从北京时间 23:35:16 左右中途加入，共记录 42 条：显存温度 54–64°C，首条 60°C、末条 54°C。GPU-Z 核心温度范围约 43.55–50.85°C。前半段显存温度未知，不补值。
- GPU-Z 的数据布局核对来源：[GpuzShMem 头文件](https://github.com/vision57/GpuzShMem/blob/master/GpuzShMem/GpuzShMem.h)。本机实际读数以随附日志为证，不把该接口的历史支持说明外推为所有显卡都可读。
