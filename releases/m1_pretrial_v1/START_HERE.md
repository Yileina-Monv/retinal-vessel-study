## 数据与定义

- 470 张训练、118 张开发验证、12 张边界案例。600 张来源都是 FIVES 官方 train；官方 test 和外部图像不参与本轮计算。
- 在完整图像上令 \(Y_F=Y\cap F\)，采用 scikit-image `zhang` 骨架化得到 \(S\)。无剪枝；短枝和单像素目标保留。
- 欧氏距离变换在完整 \(Y_F\) 上进行，外围显式补一圈背景。\(D\) 只需在骨架位置保留；原图每个像素的完整距离场不作为训练输入。
- \(M=\operatorname{dilate}(S,B_2)\cap Y_F\)，其中 \(B_2\) 为半径 2 像素的圆盘。管内半径通过最近骨架点传播；仅保存半径，不提前选择 M2 权重。
- 主分析和 M1 监督都保留完整 FOV。FOV 裁断造成的边界骨架不被悄悄删除；另外报告 FOV 向内腐蚀 2 像素后的细血管召回敏感性结果。该内域指标不能替换主指标挑选结果。
- 训练、验证和推理都不缩放原图。完整预计算图随原图裁剪、水平/垂直翻转和 90 度旋转；禁止对每个训练裁块重新骨架化。
- \(\tau=Q_{.25}(D|_S)\)、\(r_{ref}=Q_{.5}(D|_S)\) 仅使用 470 张训练图像的全部骨架像素，采用 linear 分位数。细血管图由 \(S\cap\{D\leq\tau\}\) 精确生成，避免另存一份可能过期的缓存。
- 半径单位是公开图像像素，不能解释为物理管径；同一像素阈值跨数据集的尺度局限仍存在。

## 损失与指标

\[
L_{M1}=L_{pixel}+\lambda_s\,\operatorname{mean}_{n:|M_n|>0}
\left(1-\frac{\sum_x M_n(x)\sigma(z_n(x))+10^{-6}}{|M_n|+10^{-6}}\right).
\]

像素项沿用父版本的逐图 FOV BCE＋soft Dice。无骨架裁块的骨架项为零，并记录数量；空 FOV 裁块的像素项为零，但仍占用样本序列位置。全空骨架有效批次的骨架项为零。

所有损失求和均使用 FP32。若以后使用梯度累积，必须使用整个有效 batch 的样本数与有效骨架图像数作分母；不能平均各微批次自己的均值。目前执行入口只允许 microbatch 4、accumulation 1。系数候选为 0.1 和 1.0，尚未选定。

评测包括逐图 Dice、Precision、Recall、Average Precision（AP；不是梯形积分 PR-AUC）、hard clDice、细血管召回。细血管距离容差 1 像素为主，0 和 2 像素为敏感性分析。A/D/G/N 分组各自输出样本量、有效指标数和缺失数，采用逐图宏平均。

空值规则：真值和预测都空时 Dice/clDice 为 NA；仅一方空时 Dice/clDice 为 0。没有预测阳性时 Precision 为 NA；真值没有阳性时 Recall/AP 为 NA；没有细血管真值时细血管召回为 NA。聚合保留 NA 数量，不能用 0 或 1 填充。真值存在而模型完全漏检时召回及 clDice 为 0，不从均值剔除。

## 另一台电脑的入口

1. 使用新的完整 `m1_pretrial_v1_full.zip`，按包外元数据核对整体 SHA-256。包内包含父版本与新增版本，不包含 `.venv`、训练目录或主登记表。
2. 解压到一个全新项目目录，再按 `environment/setup.ps1` 安装固定环境。不要与现有结果文件夹混合覆盖。
3. 使用新目录的 Python 运行 `python -m retinal_m1.verify`。必须同时通过父版本、全部新增文件、环境、实际裁块与初始化校验。校验失败即停止，不自动重生成预计算图。
4. 任务票据仍由原 5080 电脑的单一登记表签发。第二台电脑不复制或创建第二份主登记表；未回传的新进度明确记为未知。
5. 后续获准试跑时，使用 `retinal_m1.jobs` 签发 M0 或 M1 开发票据；明确目标机器、GPU UUID、种子、总步数及系数。`retinal_m1.run` 只执行该票据；本轮没有签发真实训练票据。
6. 暂停后沿用 `retinal_release.exchange pack/ingest` 打包和回收完整检查点。票据 ID 同时绑定方法、系数和 addon_id。旧步数、同一步冲突、不同票据和正在写入的结果继续被拒绝。

禁止同一任务跨机器/GPU续训。现有迁移验收是在同一主机改变绝对路径；RTX 4070 尚未现场验收，不声称跨 GPU 数值等价。本版 M1 训练入口的实际优化更新、暂停/恢复联调留在首次开发试跑的起始验收，不能把父版本的 M0 恢复证据直接写成 M1 恢复已验证。
